# 🎬 自媒体 / 剪辑：一条 60 秒短视频

> **这一页的实操流程：** 做一条 60 秒的科普短视频：**选题 → 查证 → 脚本和分镜 → 改自然 → 字幕 → 封面 → 发布文案**。
>
> **前置：** 主线章节（见「[按身份学](./)」第 2 节）

## 1. AI 能帮你做的事

| 场景 | 怎么做 | 用到 |
|---|---|---|
| 找选题 | 给出账号定位，让 AI 列选题并说明理由 | 直接说 |
| 查证事实 | 科普内容先查可靠来源，再写脚本 | `reliable-research` |
| 写脚本和分镜 | 口播稿 + 每个镜头拍什么，做成表格 | `xlsx` |
| 改得像人话 | 把 AI 腔改自然 | `qu-ai-wei` |
| 加字幕 | 视频语音识别，生成字幕文件并烧录 | `video-subtitle` |
| 做封面 | 按尺寸出封面图 | `canvas-design` |

## 2. 除了主线，还要看

- [第 18 章 靠谱搜索](/chapters/18-reliable-search)：科普内容最怕说错
- [第 13 章 让 DSH 自动干活](/chapters/13-automation)：每周自动出选题

## 3. 装这几个 skill

- 通用：`reliable-research`、`xlsx`、`qu-ai-wei`、`canvas-design`
- 自媒体专属：`video-subtitle`（需要先装 ffmpeg 和 Whisper，AI 会提示你怎么装）（见「[按身份找 Skill](/skill-hub/by-role)」）

## 4. 实操流程：《猫为什么爱踩奶》60 秒科普

### 第一步：准备文件夹

1. 新建文件夹 `ai-练习/短视频-猫踩奶`
2. 新建 `账号定位.md`，写几行就行：

```text
账号：萌宠冷知识
观众：养猫新手，18–35 岁
风格：轻松、口语化，每条视频只讲一个知识点，60 秒以内
```

3. DSH 选这个文件夹当工作区，权限选「工作区内修改」

### 第二步：查证

```text
用 reliable-research，查「猫为什么会踩奶」。
要求：
1. 优先找兽医、动物行为学的来源，标出每条信息的出处
2. 分清「有研究支持的」和「流行说法、没有定论的」
3. 查不到可靠来源的，直接说查不到
保存为「资料.md」
```

**检查：** 点开 2–3 个出处链接，看是不是真的这么写的。

### 第三步：脚本和分镜

```text
根据「资料.md」，写一条 60 秒的口播脚本，大约 220 字。
开头 3 秒要有一个吸引人的问题。只用资料里有出处的内容，
没有定论的要说「有一种说法是」。

再做一张分镜表，存为「分镜.xlsx」，列：
镜号、时长（秒）、画面（拍什么）、口播文字、字幕重点词。
时长加起来不超过 60 秒。
脚本保存为「脚本.md」
```

**检查：** 分镜表的时长加起来是不是 60 秒以内；每句口播能在资料里找到依据。

### 第四步：改得像人话

```text
用 qu-ai-wei 把「脚本.md」改得更口语化，像跟朋友聊天。
不要改事实，不要加新内容。改完给我看前后对比。
```

自己**大声念一遍**，念着别扭的地方再改。

### 第五步：拍摄和字幕

1. 按分镜表拍摄、剪辑，导出 `成片.mp4` 放进文件夹
2. 加字幕：

```text
用 video-subtitle 给「成片.mp4」加中文字幕。
先生成字幕文件给我检查，我确认后再烧录进视频。
```

**检查：** 逐句看字幕，改掉识别错的字。**专有名词最容易错。**

### 第六步：封面和发布文案

```text
用 canvas-design 做一张竖版封面，1080×1440，大字标题「猫踩奶是在干嘛？」，
风格简洁、明亮。另外写 3 个发布标题和一段 100 字以内的简介，带 3 个话题标签。
```

**发布这一步，自己来做。** 不要用会自动发布的 skill。

## 5. 规矩

- **事实先查证，再写脚本**。科普说错了，比不发更伤账号
- 别人的视频、音乐、图片、字体有版权；用 AI 生成的素材，也要看平台对 AI 内容的标注要求
- 拍到别人的脸、车牌、门牌号，要打码
- 自动批量发布、自动评论、刷数据的工具，不要用

## 6. 参考作品

- [dodoshell/unfaced](https://github.com/dodoshell/unfaced)（MIT）：用 AI 批量做“不露脸”短视频的完整流程。脚本写完会**停下来等人确认**，再继续配音、出画面、检查。作品展示区会拆解这个设计
