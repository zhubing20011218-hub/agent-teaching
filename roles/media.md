# 🎬 自媒体 / 剪辑：一条 60 秒短视频

> **流程：** 查证 → 脚本和分镜 → 改自然 → 字幕 → 封面和发布文案
>
> **装好：** `reliable-research`、`xlsx`、`humanizer-zh`、`canvas-design`

## 准备

新建文件夹 `ai-练习/短视频-猫踩奶`，新建 `账号定位.md`：

```text
账号：萌宠冷知识   观众：养猫新手，18–35 岁
风格：轻松口语，每条只讲一个知识点，60 秒以内
```

DSH 选这个文件夹，权限「工作区内修改」。

## 1. 查证

```text
用 reliable-research 查「猫为什么会踩奶」：优先兽医、动物行为学来源，每条标出处；
分清有研究支持的和流行说法；查不到就说查不到。保存为「资料.md」。
```

✅ **检查：** 点开 2–3 个出处看是不是真这么写的。
🔧 **不对的话：** `第 2 条的链接打不开 / 原文没这么说，删掉这条，换一个能打开的来源。`

## 2. 脚本和分镜

```text
根据「资料.md」写 60 秒口播脚本（约 220 字），开头 3 秒抛一个问题；只用有出处的内容，没定论的说「有一种说法是」。
再做分镜表「分镜.xlsx」：镜号、时长、画面、口播、字幕重点词，总时长不超过 60 秒。脚本保存为「脚本.md」。
写完先停下，等我确认。
```

✅ **检查：** 分镜时长加起来 ≤ 60 秒；每句口播在资料里有依据。

## 3. 改自然

```text
用 humanizer-zh 把「脚本.md」改得更口语，不改事实、不加内容，给我看前后对比。
```

✅ **检查：** 自己大声念一遍，别扭的地方再改。

## 4. 字幕

脚本和每个镜头的时长都已经有了，字幕可以直接生成，不用装语音识别：

```text
根据「脚本.md」和「分镜.xlsx」的时长，生成字幕文件「字幕.srt」。
每条字幕不超过 16 个字，时间按分镜表累加。
```

把 `字幕.srt` 导入剪映等剪辑软件，再按实际口播微调时间。

✅ **检查：** 逐句看字幕，专有名词最容易错；时间和画面对得上。
🔧 **时间对不上的话：** `第 5 条到第 8 条整体往后挪 1.5 秒，其他不变。`

## 5. 封面和发布文案

```text
用 canvas-design 做竖版封面 1080×1440，大字标题「猫踩奶是在干嘛？」，简洁明亮。
再写 3 个发布标题和 100 字以内简介，带 3 个话题标签。
```

**发布这一步自己来。**

## 规矩

- 先查证，再写脚本
- 别人的视频、音乐、字体有版权；拍到别人的脸、车牌要打码
- 不用自动发布、自动评论、刷数据的工具
