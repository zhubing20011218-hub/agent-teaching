# 👩‍🏫 大学老师：一周的课程包

> **流程：** 课件 → 阅读导读 → 课后练习和自测网页 → 评分标准 → 作业反馈草稿 → 成绩汇总
>
> **装好：** `pptx`、`ppt-polish`、`docx`、`xlsx`、`paper-explainer`、`study-pack`、`rubric-feedback`

## 先检查环境

这些 skill 里，有的要靠电脑上的 Python、Node.js 才能运行（不知道这是什么，先看[第 1 章 · 认识运行环境](/chapters/01-basic-skills#_5-小技能四-认识-运行环境)）：

- `pptx`：Node.js 18 以上 + 工具包 pptxgenjs；Python 3.10 以上；LibreOffice（让 AI 把 PPT 转成图片自己检查，强烈建议）
- `docx`：Node.js 18 以上 + 工具包 docx；Python 3.10 以上
- `xlsx`：Python 3.10 以上 + 工具包 openpyxl、pandas、markitdown；LibreOffice（重算公式）
- `ppt-polish`、`study-pack`、`paper-explainer`、`rubric-feedback`：只有文字说明，不需要额外环境

装好 skill 之后，在 DSH 里发（或者装了 `env-check` 就说“检查环境”）：

```text
开始之前，先检查我的电脑环境，只检查，不要安装任何东西。我要用的 skill 需要：
- pptx：Node.js 18 以上 + 工具包 pptxgenjs；Python 3.10 以上；LibreOffice（让 AI 把 PPT 转成图片自己检查，强烈建议）
- docx：Node.js 18 以上 + 工具包 docx；Python 3.10 以上
- xlsx：Python 3.10 以上 + 工具包 openpyxl、pandas、markitdown；LibreOffice（重算公式）
每一项告诉我：装了没有、版本号、够不够用，用表格列出来。
缺的东西，告诉我怎么装：需要安装包的，给我官网地址和步骤，我自己装；工具包可以你来装，但要先告诉我命令，等我同意。
全部装好后再检查一遍。
```

✅ **检查：** 表格里每一项都是“够用”。
🔧 **下载太慢的话：** `安装工具包时用国内镜像：pip 用清华源，npm 用 npmmirror，只在这次安装时使用，不要改我的全局设置。`

## 准备

1. 新建文件夹 `ai-练习/管理学原理/第5周`
2. 新建 `讲稿要点.md`，写几行：

```text
课程：管理学原理（本科二年级）  本周：激励理论，90 分钟
要讲：需要层次、双因素、期望理论，三者区别，一个企业案例
学生情况：理论记得住，不会用到案例上
作业：用一种激励理论分析一家企业，1500 字
```

3. 放进本周要学生读的论文 PDF；DSH 选这个文件夹，权限「工作区内修改」

## 1. 课件

```text
根据「讲稿要点.md」做约 20 页 PPT：每页一个重点，字号不小于 24，三个理论各一页对比表，案例部分留讨论题。
理论提出者、年份、引文拿不准的标「（请核对）」。保存为「第5周.pptx」。做完用 ppt-polish 检查一遍。
```

✅ **检查：** 从头翻一遍，所有「（请核对）」对照教材改好。
🔧 **不对的话：** `第 6 页内容太多，拆成两页；第 9 页的年份改成 1959。`

## 2. 阅读导读

```text
用 paper-explainer 读「论文.pdf」，读者是本科二年级。在阅读笔记的基础上，再写一份给学生的导读：论文回答什么问题（3 句）、重点读哪几节（标页码）、3 个课前思考题、术语解释。保存为「阅读导读.docx」。
```

✅ **检查：** 页码和观点回原文核对。

## 3. 课后练习和自测网页

```text
根据课件出 15 道题（选择 8、判断 4、案例分析 3），标对应页码，答案解析放最后，保存为「课后练习.md」。
再用 study-pack 的自测网页功能，把选择题和判断题做成学生自测网页。
```

✅ **检查：** 自己把题做一遍。自测网页是离线文件，不收集学生信息，可以直接发到课程群。

## 4. 评分标准

```text
为本周作业写评分标准，满分 100：理论理解、案例分析、论证逻辑、写作规范，每项分优良中差四档，写清要求和分数区间。保存为「评分标准.md」。
```

## 5. 作业反馈草稿

先把作业里的姓名换成学号，放进 `作业/` 文件夹。

```text
用 rubric-feedback，按「评分标准.md」批阅「作业/」里的所有作业，每份一个反馈文件，最后给我汇总表。
```

✅ **检查：** **每一份都看**：证据是不是真在学生原文里、建议档位同不同意。分数你来定。
🔧 **不对的话：** `学号 2024003 的“论证逻辑”证据引用不在原文里，重新找原文证据，找不到就写“未找到”。`

## 6. 成绩汇总

```text
用 xlsx 把汇总表和我确定的分数整理成成绩表，算平均分、最高分、最低分，画分数分布图。
```

## 规矩

- AI 写的是草稿，**分数和评语由你决定**
- 学生姓名、成绩、作业只走学校网关或官方接口，不走公开中转站（第 9 章）
- AI 检测“学生是否用了 AI”只能参考，不能单凭它认定学术不端
