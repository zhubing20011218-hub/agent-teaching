# ✈️ 旅行爱好者：3 天行程

> **流程：** 让 AI 先问清楚 → 行程 → 预算表 → 核对官方信息 → 手机行程页 → 出发前再核对
>
> **装好：** `travel-planning-skill`（或只问答不联网的 `lele`）、`xlsx`、`reliable-research`、`travel-itinerary`

## 准备

新建文件夹 `ai-练习/杭州3天`，DSH 选它当工作区，权限「工作区内修改」。

## 1. 先让 AI 问你

```text
我想去杭州玩 3 天，用 travel-planning-skill 规划。先别急着排，先问我问题，问清楚再规划。
```

照实回答它的问题：几个人、什么时候、预算、喜好、体力。

## 2. 出行程

✅ **检查：** 每天的景点顺不顺路；时间有没有排太满；哪些要提前预约。
🔧 **不满意的话：** `第二天太赶了，去掉一个景点，留出午休。`

## 3. 预算表

```text
根据行程做「预算.xlsx」：交通、住宿、门票、餐饮、其他，每项写单价、数量、小计，最后总计。
查不到的价格写「待查」，不要估。
```

✅ **检查：** 「待查」的自己补上；总计用 Excel 自己求和核对。

## 4. 核对信息（最重要）

```text
用 reliable-research 核对行程里每个景点的开放时间、门票、是否要预约。
只用景区官网、官方公众号、政府网站，标来源和查询日期；和行程不一样的列出来。
```

🔧 **查不到官方来源的话：** `这个景点查不到官方信息，请标「待核实」，不要用第三方网站的说法。`

## 5. 手机行程页

```text
用 travel-itinerary 把最终行程做成手机能看的网页，每天一页：时间、地点、怎么去、注意事项。
```

## 6. 出发前一天

```text
明天出发。再核对一次第一天所有景点的开放情况和天气，有变化告诉我。
```

## 规矩

- 出发前一定再核对一次
- 护照号、身份证号、订单号不发给 AI
- 签证、出入境政策只看官方网站
