# ✈️ 旅行爱好者：3 天行程，先问清楚再出发

> **这一页的实操流程：** 规划一次 3 天的旅行：**说清需求 → 排路线 → 算预算 → 核对信息 → 做成手机能看的行程页 → 出发前再核对一次**。
>
> **前置：** 主线章节（见「[按身份学](./)」第 2 节）

## 1. AI 能帮你做的事

| 场景 | 怎么做 | 用到 |
|---|---|---|
| 排行程 | 先回答 AI 的问题，再让它排顺路的路线 | `travel-planning-skill` 或 `lele` |
| 做手机行程页 | 行程做成网页，出门用手机看 | `travel-itinerary` |
| 算预算 | 交通、住宿、门票、吃饭分开算 | `xlsx` |
| 核对信息 | 开放时间、票价、预约规则查官方来源 | `reliable-research` |

## 2. 除了主线，还要看

- [第 18 章 靠谱搜索](/chapters/18-reliable-search)：**旅行信息变化快，最容易出错**

## 3. 装这几个 skill

- 通用：`xlsx`、`reliable-research`
- 旅行专属：`travel-planning-skill`（会联网查地图），或者 `lele`（只问答，不联网）；想要手机行程页再加 `travel-itinerary`（见「[按身份找 Skill](/skill-hub/by-role)」）

## 4. 实操流程：杭州 3 天

### 第一步：准备文件夹

1. 新建文件夹 `ai-练习/杭州3天`
2. DSH 选这个文件夹当工作区，权限选「工作区内修改」

### 第二步：先让 AI 问你

```text
我想去杭州玩 3 天，请用 travel-planning-skill 帮我规划。
先别急着排，先问我问题，问清楚再规划。
```

**AI 会做什么（示例）：** 问你几个问题：几个人、什么时候去、预算多少、喜欢自然风光还是人文、走路多不多、住在哪一带……

照实回答。**问得越细，行程越合你心意。**

### 第三步：出行程

回答完，AI 会给出一份按天、按时间段排好的行程。

**检查：**
- 每天的景点是不是顺路，有没有来回折腾
- 时间是不是排太满了：吃饭、排队、休息都要留时间
- 有没有景点要**提前预约**

不满意就直接说：“第二天太赶了，去掉一个景点。”

### 第四步：预算表

```text
根据行程做一份预算表，保存为「预算.xlsx」。
分交通、住宿、门票、餐饮、其他五类，每项写单价、数量、小计，最后算总计。
价格查不到的写「待查」，不要估一个数填进去。
```

**检查：** 把「待查」的项目自己查一下补上；总计用 Excel 自己求和核对一遍。

### 第五步：核对信息

```text
用 reliable-research 核对行程里每个景点的：开放时间、门票价格、是否需要预约。
只用景区官网、官方公众号、政府网站的信息，标出来源和查询日期。
和行程里写的不一样的，列出来。
```

**这一步最重要。** AI 记住的信息可能是旧的，景区随时会调整开放时间、门票和预约规则。

### 第六步：做成手机行程页

```text
用 travel-itinerary 把最终行程做成手机能看的网页，
每天一页，写上时间、地点、怎么去、注意事项。
```

### 第七步：出发前一天

```text
明天出发。请再核对一次第一天所有景点的开放情况和天气，有变化就告诉我。
```

## 5. 规矩

- **出发前一定再核对一次**：AI 给的旧信息，可能让你白跑一趟
- 护照号、身份证号、订单号、酒店确认号**不发给 AI**
- 签证、出入境政策，只以官方网站为准
