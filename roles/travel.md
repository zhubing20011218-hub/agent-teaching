# ✈️ 旅行爱好者：3 天行程

> **流程：** 让 AI 先问清楚 → 行程和预算 → 核对官方信息 → 手机行程页 → 出发前再核对
>
> **装好：** `trip-planner`（本教程自带）、`reliable-research`、`xlsx`

## 先检查环境

这些 skill 里，有的要靠电脑上的 Python、Node.js 才能运行（不知道这是什么，先看[第 1 章 · 认识运行环境](/chapters/01-basic-skills#_5-小技能四-认识-运行环境)）：

- `xlsx`（预算表）：Python 3.10 以上 + 工具包 openpyxl、pandas
- `trip-planner`、`reliable-research`：只有文字说明，不需要额外环境

装好 skill 之后，在 DSH 里发（或者装了 `env-check` 就说“检查环境”）：

```text
开始之前，先检查我的电脑环境，只检查，不要安装任何东西。我要用的 skill 需要：
- xlsx（预算表）：Python 3.10 以上 + 工具包 openpyxl、pandas
每一项告诉我：装了没有、版本号、够不够用，用表格列出来。
缺的东西，告诉我怎么装：需要安装包的，给我官网地址和步骤，我自己装；工具包可以你来装，但要先告诉我命令，等我同意。
全部装好后再检查一遍。
```

✅ **检查：** 表格里每一项都是“够用”。
🔧 **下载太慢的话：** `安装工具包时用国内镜像：pip 用清华源，npm 用 npmmirror，只在这次安装时使用，不要改我的全局设置。`

## 准备

新建文件夹 `ai-练习/杭州3天`，DSH 选它当工作区，权限「工作区内修改」。

## 1. 先让 AI 问你

```text
用 trip-planner 帮我规划杭州 3 天。先问我问题，问清楚再排。
```

照实回答：几个人、什么时候、预算、喜好、体力。

## 2. 行程和预算

回答完，AI 会生成 `行程.md`、`预算.xlsx` 和 `出发前核对.md`。

✅ **检查：** 每天的景点顺不顺路；有没有排太满；预算表里没有凭空估的数，查不到的写着「待查」。
🔧 **不满意的话：** `第二天太赶了，去掉一个景点，留出午休。`

## 3. 核对信息（最重要）

```text
用 reliable-research，按「出发前核对.md」逐条核对开放时间、门票、预约方式。
只用景区官网、官方公众号、政府网站，标来源和查询日期；查不到的保留「待核对」。
```

🔧 **查不到官方来源的话：** `这个景点查不到官方信息，请保留「待核对」，不要用第三方网站的说法。`

## 4. 手机行程页

```text
把最终行程做成一个手机能看的单页网页「行程.html」：每天一节，写时间、地点、怎么去、注意事项。
只用一个文件，不加载外部资源。
```

## 5. 出发前一天

```text
明天出发。再核对一次第一天所有景点的开放情况和天气，有变化告诉我。
```

## 规矩

- 出发前一定再核对一次
- 护照号、身份证号、订单号不发给 AI
- 签证、出入境政策只看官方网站
