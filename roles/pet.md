# 🐾 宠物主人：毛孩子的照护档案

> **流程：** 建档 → 记录疫苗驱虫体重 → 提醒清单 → 每月自动提醒 → 看病前整理一页纸
>
> **装好：** `pet-care-log`（本教程自带）、`xlsx`、`reliable-research`

## 准备

新建文件夹 `ai-练习/豆豆`，DSH 选它当工作区，权限「工作区内修改」。

## 1. 建档

```text
帮我给猫建档：名字豆豆，英短，母猫，2024 年 3 月出生，已绝育。
```

✅ **检查：** 出现 `宠物记录/档案.md`，信息对。

## 2. 补历史记录

```text
记一下豆豆的记录：
- 2026-03-10 打了猫三联加强针，兽医说明年 3 月再打
- 2026-10-01 体内驱虫，兽医说 3 个月一次
- 2026-10-15 体外驱虫
- 2026-11-01 体重 4.2 公斤
```

✅ **检查：** 打开 `照护记录.csv`，日期和下次日期对。体外驱虫没说间隔，下次日期应该是空的，并提醒你问兽医。
🔧 **它自己填了间隔的话：** `体外驱虫的下次日期兽医没说，请留空，不要自己定。`

## 3. 看接下来要做什么

```text
接下来豆豆有哪些事要做？
```

## 4. 每月自动提醒

```text
建一个定时任务：每月 1 号早上 9 点，读「宠物记录/提醒清单.md」，列出未来 30 天要做的事，过期没做的放最前面。
```

✅ **检查：** 定时任务列表里能看到它（第 17 章）。

## 5. 体重曲线

```text
用 xlsx 把豆豆的体重记录做成折线图，保存为「体重变化.xlsx」。
```

## 6. 看病前的一页纸

```text
豆豆这两天不爱吃东西，明天去看兽医。把最近 3 个月的记录、疫苗驱虫情况整理成一页，不要做任何诊断。
```

> [!WARNING]
> AI 不能代替兽医。不吃东西、呕吐、精神差，要尽快去医院。
