# 按身份学：先选一个身份

> **认识 AI 只是开始，用 AI 把你手上的事做完，才是真正有用的。**
>
> 这里给 7 种身份，每一种都有：AI 能帮你做的事、你必须看的章节、该装的 skill、**一套从头到尾的实操流程**，还有安全规矩。

## 1. 选一个和你最像的

| 身份 | 实操流程做什么 | 去看看 |
|---|---|---|
| 🎓 大学生 | 期末复习：课件变成复习手册和自测网页；读懂一篇论文 | [大学生](student) |
| 👩‍🏫 大学老师 | 一周的课程包：课件、阅读导读、自测网页、作业反馈草稿 | [大学老师](teacher) |
| 🧾 会计 / 财务 | 银行流水和台账对账，找出差异，写复核说明 | [会计](accounting) |
| 🛒 电商运营 | 新品上架包：标题、卖点、详情文案、客服问答 | [电商](ecommerce) |
| 🎬 自媒体 / 剪辑 | 一条 60 秒短视频：选题、查证、脚本分镜、字幕、封面 | [自媒体](media) |
| 🐾 宠物主人 | 给毛孩子建档，记录疫苗驱虫，自动提醒 | [宠物主人](pet) |
| ✈️ 旅行爱好者 | 3 天行程：先问清楚，再排路线、算预算、核对信息 | [旅行](travel) |

不确定选哪个？选**大学生**。它的流程最简单，学会了再看别的。

## 3. 每套实操流程都是同一个节奏

1. **先检查环境**：让 AI 看看电脑上有没有需要的 Python、Node.js，缺的带你装好
2. **建一个专用文件夹**，放资料（先用假数据或公开资料练）
3. **装需要的 skill**
4. **一步一步对 AI 说话**，每一步都有现成的话可以复制
5. **每一步都检查**：页面上会告诉你查什么、怎么查
6. **满意的做法存下来**，下次直接用，或者写成你自己的 skill

> [!TIP]
> 页面里的“AI 回复”都是**示例**。AI 每次说的话不一样，只要意思对上就行。不对的时候，看每一步后面的“检查”。

## 4. 用 AI 的三条底线

1. **重要的结果自己核对**：数字、日期、引用、法律和医疗信息
2. **敏感资料不乱发**：身份证、密码、客户数据、学生信息，见[第 9 章](/chapters/09-relay-station)
3. **该自己负责的事不交给 AI**：交作业、签字、打分、投资、看病
