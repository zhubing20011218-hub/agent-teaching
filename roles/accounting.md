# 🧾 会计 / 财务：对账找差异

> **流程：** 银行流水和台账对一遍 → 找出差异 → 写复核说明。用**假数据**练。
>
> **装好：** `xlsx`、`docx`、`reconciliation`
>
> **最重要的一条：** 算数交给程序，不交给 AI 心算。

## 先检查环境

这些 skill 里，有的要靠电脑上的 Python、Node.js 才能运行（不知道这是什么，先看[第 1 章 · 认识运行环境](/chapters/01-basic-skills#_5-小技能四-认识-运行环境)）：

- `xlsx`：Python 3.10 以上 + 工具包 openpyxl、pandas、markitdown；LibreOffice（重算公式，建议装）
- `docx`：Node.js 18 以上 + 工具包 docx；Python 3.10 以上
- `reconciliation`：只有文字说明，不需要额外环境

装好 skill 之后，在 DSH 里发（或者装了 `env-check` 就说“检查环境”）：

```text
开始之前，先检查我的电脑环境，只检查，不要安装任何东西。我要用的 skill 需要：
- xlsx：Python 3.10 以上 + 工具包 openpyxl、pandas、markitdown；LibreOffice（重算公式，建议装）
- docx：Node.js 18 以上 + 工具包 docx；Python 3.10 以上
每一项告诉我：装了没有、版本号、够不够用，用表格列出来。
缺的东西，告诉我怎么装：需要安装包的，给我官网地址和步骤，我自己装；工具包可以你来装，但要先告诉我命令，等我同意。
全部装好后再检查一遍。
```

✅ **检查：** 表格里每一项都是“够用”。
🔧 **下载太慢的话：** `安装工具包时用国内镜像：pip 用清华源，npm 用 npmmirror，只在这次安装时使用，不要改我的全局设置。`

## 准备

新建文件夹 `ai-练习/对账练习`，新建两个文件，原样复制下面的内容。DSH 选这个文件夹，权限「工作区内修改」。

`银行流水.csv`：

```text
日期,对方户名,摘要,收入,支出
2026-10-08,华星文具,货款,12000.00,
2026-10-09,,手续费,,15.00
2026-10-10,明远物流,运费,,3200.00
2026-10-12,蓝海科技,货款,8600.00,
2026-10-15,房东王某,房租,,6500.00
2026-10-18,华星文具,货款,5400.00,
2026-10-20,电力公司,电费,,820.50
2026-10-25,工资代发,工资,,28000.00
```

`台账.csv`：

```text
日期,单位,事项,收款,付款
2026-10-08,华星文具,收货款,12000.00,
2026-10-10,明远物流,付运费,,3200.00
2026-10-12,蓝海科技,收货款,6800.00,
2026-10-15,房东,付房租,,6500.00
2026-10-18,华星文具,收货款,5400.00,
2026-10-20,电力公司,付电费,,820.50
2026-10-25,工资,发工资,,28000.00
2026-10-28,云帆贸易,收货款,9900.00,
```

这两张表里藏了 **3 处差异**。

## 1. 对账

```text
用 xlsx 对比「银行流水.csv」和「台账.csv」，用程序计算，不要心算。
按日期和金额匹配，日期允许差 3 天。输出「对账结果.xlsx」：已匹配、只在银行、只在台账三个工作表，金额不一致的标红。
最后写出两边的收入合计、支出合计和差额。
```

✅ **检查：** 用 Excel 自己求和，和 AI 给的合计对一对；看找到了几处差异。
🔧 **不对的话：** `合计和我用 Excel 算的不一样，请重新用程序计算并把计算过程列出来。`

<details>
<summary>3 处差异的参考答案</summary>

| 差异 | 情况 | 可能原因 |
|---|---|---|
| 10-09 手续费 15.00 | 只在银行 | 台账漏记手续费 |
| 10-12 蓝海科技 | 银行 8600，台账 6800 | 录入时数字颠倒 |
| 10-28 云帆贸易 9900 | 只在台账 | 款项在途，下月核对 |

</details>

## 2. 复核说明

```text
根据「对账结果.xlsx」写对账复核说明：先写结论（几处差异、金额多少），再逐条写日期、金额、情况、可能原因、建议处理。
原因只是推测，标「待核实」；不要编原始数据里没有的信息。保存为「对账说明.docx」。
```

✅ **检查：** 每条差异的金额回原表核对。原因要你查凭证确认。

## 换成真实数据之前

- 客户名称、账号先去掉，或者换成代号
- 只走官方接口或单位网关，不走公开中转站（第 9 章）
- 用 `reconciliation`（Anthropic 官方的对账 skill）按银行对账、往来对账的标准流程做，每笔差异都要写原因和处理建议
- 结果是底稿，最后要人工复核、签字
