# 🎓 大学生：期末复习和读论文

> **流程 A：** 一周的课件 → 复习手册 → 题库 → 自测网页
> **流程 B：** 读懂一篇论文，记成笔记
>
> **装好：** `pdf`、`lecture-notes`、`quiz-generator`、`sunzi-reading`、`paper-reading`（点名字跳到 Skill 库，复制安装指令）
> **先看：** 学校和这门课的 AI 使用规定

## 准备

1. 新建文件夹 `ai-练习/期末复习`，放进一周的课件 PDF
2. DSH 选这个文件夹当工作区，权限选「工作区内修改」

## 流程 A：期末复习

### 1. 课件 → 复习手册

```text
用 lecture-notes，把「第5周.pdf」整理成中文复习手册：
每个概念先一句大白话、再写课件原定义；例题写完整步骤；每条标课件页码。
课件没有的不要加，拿不准的标「（不确定）」。
```

✅ **检查：** 挑 3 个概念、1 道例题，翻回课件核对页码和答案。
🔧 **不对的话：** `第 3 条的页码不对，课件里在第 12 页，请改正并重新检查所有页码。`

### 2. 出题

```text
根据复习手册出 20 道题（选择 10、判断 5、简答 5），每题标对应页码，答案解析放最后，保存为「题库.md」。
```

✅ **检查：** 自己先做 5 道再对答案。
🔧 **不对的话：** `第 7 题答案和课件第 15 页说的不一样，以课件为准改正，再检查其他答案。`

### 3. 做成自测网页

```text
用 quiz-generator 把「题库.md」做成离线自测网页。
```

✅ **检查：** 双击生成的网页，能做题、有错题本。
🔧 **打不开的话：** `网页打不开 / 是空白的，请检查并修复，告诉我用哪个文件打开。`

### 4. 错题再讲

```text
我错了第 3、7、15 题。换个说法讲这几个概念，每讲完出一道新题考我。
```

## 流程 B：读懂一篇论文

```text
用 sunzi-reading 给我讲「论文.pdf」：解决什么问题、怎么做的、发现了什么、有什么局限。我是本科生。
```

```text
用 paper-reading 精读，写中文阅读笔记：研究问题、方法、结论、可以引用的观点（标页码）、我还没看懂的地方。保存为「阅读笔记.md」。
```

✅ **检查：** 笔记里每个“可以引用的观点”回原文核对；AI 推荐的参考文献，每一篇都去数据库搜到原文。
🔧 **找不到出处的话：** `这条观点我在原文第 X 页没找到，请给出原文原句；找不到就删掉。`

> [!WARNING]
> 笔记是帮你读懂的。写进论文要用自己的话、按规范引用。

## 规矩

- 遵守学校和课程的 AI 规定，该说明的要说明
- 不碰“降 AIGC 率”“过查重”“自动生成实验报告”（见 [Skill 库 · 不收录](/skill-hub/#avoid)）
- 学校有 AI 网关的优先用学校的（第 9 章）
