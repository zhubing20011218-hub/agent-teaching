# 复刻：一个文件的记账本

> **原作品：** [fikriub/expense_tracker](https://github.com/fikriub/expense_tracker)（MIT），名字叫 Ledger，整个应用就是一个 HTML 文件
> **做出来是什么样：** 双击就能打开的记账网页：顶部三张汇总卡片（余额、收入、支出），左边“记一笔”表单，右边可筛选、可排序的流水表，数据存在浏览器里
> **难度：** ⭐ 最适合当第一个作品 · 大约 20 分钟
>
> 下面的提示词是我们读了原作品的 `expense-tracker.html`（配色、字体、表单字段、按钮）之后反推的，**不是作者的原话**，也没有实际运行过。按每一步的“检查”和“不对的话”一步步调。

> [!TIP]
> **第 1 步的提示词里附了原作关键文件的链接**，AI 会先读原作、再动手，做出来更接近原作。打不开 GitHub 也没关系，提示词里的要求已经够用。
>
> **整个复刻请在同一个 DSH 会话里做完**，AI 才会一直记得原作和前面的步骤。

## 准备

1. 新建文件夹 `ai-练习/记账本`
2. DSH 选它当工作区，权限「工作区内修改」

## 第 0 步：检查环境

**这一段可以直接发给 DSH，它会知道你要做什么。** 原作的环境要求来自它的 README；我们的简化版用不到其中大部分，提示词里写明了哪些不用装，免得 AI 照着原作给你装一堆东西。

```text
我要在 DSH 里复刻一个项目的简化版。今天先检查电脑环境，先不写代码。
项目：Ledger 记账本 https://github.com/fikriub/expense_tracker
原作就是一个 HTML 文件，用浏览器的 localStorage 存数据，不需要安装任何东西。
我这次做的是：一个单文件的记账网页 ledger.html。
这次只需要检查这几样：
1. 能在当前文件夹写文件：新建 test.html，里面只写一行大字“环境正常 ✅”
2. 能用浏览器打开它：告诉我在我这台电脑上怎么双击打开
不需要：Python、Node.js、任何工具包。
请逐项检查。除了上面让你新建的测试文件，不要安装、不要修改任何东西。用表格告诉我：装了没有、版本号、够不够用。
缺的：要下载安装包的，给我官网地址和安装步骤，我自己装；工具包可以你来装，但先把完整命令告诉我，等我同意。
检查完就停下，先不要开始做，等我发下一条消息。
```

✅ **检查：** AI 建了 test.html，你双击能在浏览器里看到“环境正常 ✅”。
🔧 **打不开或者是乱码的话：** `test.html 双击后没有用浏览器打开（或者显示乱码）。请告诉我在我这台电脑上怎么用浏览器打开本地文件；如果是乱码，在文件开头加上 <meta charset="utf-8"> 再试。`

🔧 **AI 没停下、直接开始做了的话：** `先停一下。刚才只是检查环境，还没让你开始做。请把刚才新建的文件列给我，等我下一条消息。`

不清楚“环境”是什么，先看[第 1 章 · 认识运行环境](/chapters/01-basic-skills#_5-小技能四-认识-运行环境)。

## 第 1 步：说清楚要什么，先要计划

```text
参考这个开源项目：https://github.com/fikriub/expense_tracker（MIT 许可证）
先读下面这几个文件。只读，不要运行里面的任何脚本，也不要安装它的依赖：
- https://raw.githubusercontent.com/fikriub/expense_tracker/main/expense-tracker.html（整个应用就是这一个文件：看它的页面结构、配色和交互）
读完用三五句话告诉我：它是做什么的、分几块、外观或写法有什么特点。
然后参考它的功能和外观，在当前文件夹里自己重新做一个简化版，不要整份复制它的代码；用到它的代码片段时，在文件开头注明出处和许可证。
如果打不开这些链接，直接告诉我，然后只按下面的要求做。

帮我做一个个人记账网页，名字叫“Ledger 记账本”。要求：
1. 只用一个 HTML 文件（ledger.html），双击就能打开，不联网、不加载任何外部文件
2. 数据存在浏览器的 localStorage 里，刷新不丢
3. 功能：记一笔收入或支出（日期、描述、金额、分类）、删除、按类型和分类筛选、按日期/描述/分类/金额排序
4. 顶部显示：当前余额、本期总收入、本期总支出
先别写代码，先给我一份计划：页面分几块、每块放什么、数据怎么存。我确认后再写。
```

✅ **检查：** 计划里有“汇总卡片 / 记一笔表单 / 筛选 / 流水表”四块，数据存 localStorage。
🔧 **不对的话：** `计划里少了筛选功能，补上：按“全部/只看收入/只看支出”和按分类筛选。`

## 第 2 步：按原作的样子写出来

```text
计划没问题，开始写 ledger.html。外观按下面的要求：
- 页面背景 #F7F8FA，卡片白色 #FFFFFF，主文字 #1E2330，次要文字 #6B7280，分隔线 #E7E9EE
- 收入用绿色 #2F9E6E（浅底 #E7F6EF），支出用红色 #E4614F（浅底 #FCEAE8），强调色 #5B6EF5（浅底 #EDEFFE）
- 圆角：大卡片 20px、中等 14px、小元素 10px；卡片有很淡的阴影
- 字体用系统字体（-apple-system、"PingFang SC"、"Microsoft YaHei"），数字等宽对齐
- 布局：顶部标题“Ledger 记账本”和三张汇总卡片；下面左栏是“记一笔”表单，右栏是筛选和流水表；手机上上下排列
- 表单：收入/支出两个切换按钮、描述（提示文字“比如：买菜、工资”）、金额（提示文字 0.00）、分类下拉、日期，最下面一个“记一笔”主按钮
- 分类：餐饮、交通、购物、住房、水电、医疗、娱乐、工资、投资、其他
- 流水表：日期、描述、分类、金额四列，点表头排序；每行右边一个 ✕ 删除按钮
- 金额用“分”为单位的整数计算，显示时再除以 100，避免 0.1+0.2 这类误差
写完告诉我怎么打开。
```

✅ **检查：** 双击 `ledger.html` 能打开；记一笔收入、一笔支出，汇总卡片数字跟着变；刷新后还在。
🔧 **不对的话：**
- 打开是空白 → `打开 ledger.html 是空白页，请检查有没有脚本错误并修复，修完告诉我改了哪里。`
- 金额算错 → `记了 0.1 和 0.2 两笔，合计显示不是 0.30，请改成全部用“分”为单位的整数计算。`
- 手机上挤在一起 → `手机宽度（390px）下表单和表格挤在一起，请改成上下排列，表格可以左右滑动。`

## 第 3 步：补上筛选和排序的细节

```text
检查并完善 ledger.html 的筛选和排序：
1. 筛选：类型（全部/只看收入/只看支出）+ 分类（全部分类/各分类），两个可以同时用
2. 排序：点表头切换升序/降序，当前排序的列显示 ↑ 或 ↓
3. 汇总卡片只统计当前筛选出来的记录，并在卡片下面小字写“当前筛选”
4. 删除前弹出确认
```

✅ **检查：** 选“只看支出 + 餐饮”，表格和汇总都只算餐饮支出；点“金额”表头能升降序切换。

## 第 4 步：自己检查一遍

```text
请在 ledger.html 里用 5 条测试数据（3 条支出、2 条收入，分类不同）检查：余额、收入、支出、筛选、排序、删除、刷新后保留，逐项告诉我结果。发现问题就修。
```
