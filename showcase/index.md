# 作品展示：AI 真的能做出什么

> GitHub 和网上**真实存在**的作品，按身份分好了。每一个都写了：成品是什么、作者怎么做的、证据在哪里，还有一句**可以直接发给 DSH 的提示词**，让你做一个简化版。
>
> 开发过程只写有证据的部分（提交记录、项目里的说明文档、作者自述），不替作者编故事。

<ShowcaseList />

## 这些作品的共同点

1. **先写计划，确认后再动手**
2. **把规矩写下来**：CLAUDE.md、AGENTS.md、skill，AI 每次都照着做
3. **关键节点停下来让人确认**，发布、付款、交作业这类事自己来
4. **从一个文件就能跑的小工具开始**，用起来再慢慢扩充
