# 复刻：家庭事务管家

> **原作品：** [micasa-dev/micasa](https://github.com/micasa-dev/micasa)（Apache-2.0，1,200 多星）
> **做出来是什么样：** 一个键盘操作的“家里的事”管理工具：定期保养（多久做一次、下次什么时候）、家里的项目、家电和保修、联系过的师傅和报价。外观像终端：深色、等宽字体、表格、用键盘上下移动
> **简化了什么：** 原作是用 Go 写的终端程序；这里做成**一个网页文件**，模仿终端的样子和键盘操作。同样的做法也能用来管宠物的疫苗、驱虫
> **难度：** ⭐⭐⭐ · 大约 1.5 小时
>
> 下面的提示词是我们读了原作的 `README.md`（功能和键盘操作）、`AGENTS.md`（给 AI 的规矩）、`.claude/commands/`（作者常用的 AI 命令，比如新增数据类型、检查文档）之后反推的，**不是作者的原话**，也没有实际运行过。
>
> **这个作品最值得学的是做法：** 项目一大，就先写 `AGENTS.md` 定规矩；把重复的操作写成固定命令。

## 准备

1. 新建文件夹 `ai-练习/家庭管家`
2. DSH 选它当工作区，权限「工作区内修改」

## 第 1 步：先写规矩

```text
我要做一个家庭事务管家网页 home.html。先写 AGENTS.md，规定：
1. 只用一个 HTML 文件，不联网、不加载外部资源；数据存 localStorage，可以导出、导入 JSON 备份
2. 每次改动前先说要改什么，改完自己检查一遍：新增、修改、删除、刷新后保留
3. 日期一律用 YYYY-MM-DD；金额用“分”为单位的整数
4. 不删除任何数据之前，先弹确认
```

## 第 2 步：数据结构

```text
按 AGENTS.md，先设计数据结构给我看，不写界面：
- 保养计划：名称、间隔天数、上次完成日期、下次到期日（自动算）、备注
- 项目：名称、状态（想法/计划中/进行中/完成/放弃）、预算、实际花费
- 家电：名称、品牌型号、购买日期、保修到期日
- 师傅和报价：姓名、电话、做过什么、报价金额、日期
```

✅ **检查：** 四类数据的字段都对；“下次到期日”是算出来的，不用手填。

## 第 3 步：终端风格的界面

```text
结构没问题，开始写 home.html，外观像终端程序：
- 深色背景 #1E1E2E，文字 #CDD6F4，强调 #89B4FA，到期提醒 #F9E2AF，过期 #F38BA8，完成 #A6E3A1
- 全部用等宽字体（"SF Mono"、Menlo、Consolas、"Microsoft YaHei Mono"）
- 顶部一排标签：保养 / 项目 / 家电 / 师傅，按 1–4 切换
- 每个标签是一张表格，当前行高亮
- 键盘操作：j/k 上下移动，/ 搜索，n 新建，e 编辑当前行，d 删除（要确认），x 把保养标记为“今天完成”，? 显示快捷键帮助
- 底部一行状态栏：当前模式、共几条、有几条快到期
```

✅ **检查：** 打开后不用鼠标，按 `n` 新建一条保养，按 `x` 标记完成，“下次到期日”自动往后推。
🔧 **不对的话：**
- 按键没反应 → `按 j/k 没反应，请检查键盘事件是不是只在输入框外生效，修复后告诉我。`
- 到期颜色不对 → `下次到期日在 7 天内要显示黄色 #F9E2AF，已经过期显示红色 #F38BA8，请修正。`

## 第 4 步：首页提醒

```text
打开网页时，先在最上面显示一句话：“有 N 项保养 7 天内到期，M 项已经过期”，下面列出它们。
```

## 第 5 步：把常用操作写成命令

原作者把“新增一种数据类型”写成了固定的 AI 命令。你也可以：

```text
写一个 skill：.dsh/skills/home-add-type/，作用是“给 home.html 新增一种数据类型”。
步骤：先问新类型的名称和字段 → 更新数据结构 → 加一个标签页和表格 → 加快捷键 → 自己检查新增、修改、删除、刷新。
```

然后试一下：

```text
用 home-add-type 新增一种数据类型“宠物照护”：宠物名、项目（疫苗/驱虫/洗澡）、间隔天数、上次日期、下次到期日。
```
