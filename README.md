# Agent 小白教程:从零开始,让 AI 真的帮你干活

一份**写给零编程基础的人**的中文教程,会持续更新。

## 学习路线

🟢 主线 = 不用写代码,所有人都学;🟡 选修 = 要写一点代码,跳过也不影响主线。

| 部分 | 学什么 | 要写代码吗 |
|---|---|---|
| 第 0 部分 开始之前 | 怎么用这份教程、终端是什么、怎么复制粘贴命令 | 不用 |
| 第一部分 弄懂概念 | 大模型、Agent、API、Harness 分别是什么 | 不用 |
| 第二部分 拿到钥匙 | 申请 DeepSeek API 钥匙;🟡 亲手调用一次、手写迷你 Agent | 主线不用 |
| 第三部分 用上 DSH | 安装、填钥匙、让它帮你干活;🟡 自动化 | 主线不用 |
| 第四部分 Skill | skill 是什么、怎么装、**做 PPT、美化 PPT、搜靠谱资料**、自己写 skill | 不用(写的是普通文字) |
| 第五部分 进阶定制 | MCP、插件、定制你的 Agent;🟡 开发插件 | 主线不用 |
| 第六部分 实战与安全 | 综合实战、安全、怎么少花钱 | 不用 |

## 关于"持续更新"

DeepSeek Harness 还在快速更新(调研时是 0.2.2 预发布版)。所以:

- 每章开头写明**用哪个版本验证过**、**哪天验证的**。
- 容易变的界面细节,都附上官方文档链接。
- 版本变化对教程的影响,记在附录「更新日志」里。

如果你发现某一步和你看到的画面不一样,欢迎提 Issue。
