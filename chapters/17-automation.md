# 第 17 章 让 DSH 自动干活

> 🟡 **这是选修章。** 第一节“定时任务”不用写代码，所有人都可以看；后面两节要用终端和代码。

> **学完这一章，你能：**
> - 让 DSH 每天定时自动做一件事
> - 用一条命令让 DSH 做完一件事就退出
> - 知道怎么从 Python 程序里调用 DSH
>
> **前置：** 第 10 章

## 1. 为什么要学这个

前面都是“你说一句，它做一件”。但有些事你希望它**自己定时做**，比如：

- 每天早上 9 点，整理昨天下载的文件
- 每周五下午，把本周的笔记汇总成一份周报

## 2. 定时任务（不用写代码）

DSH 里叫「**自动化任务**」。有两种建法：

### 方法一：直接跟 AI 说（最简单）

在会话里输入：

```
每天 Asia/Shanghai 时区早上 9:00,帮我检查 ai-练习/乱七八糟 文件夹,
把新出现的文件按类型放进对应的子文件夹,然后告诉我移动了哪些文件。
```

> [!TIP]
> 写上时区(中国用 `Asia/Shanghai`，马来西亚用 `Asia/Kuala_Lumpur`)，避免时间算错。

**应该看到：** AI 回复下方出现一张卡片，显示任务名称和频率。点「打开」可以看详情。

### 方法二：手动创建

1. 在左边栏打开「**自动化任务**」页面
2. 点「新建」旁边的「选择创建方式」→「**手动创建**」
3. 填写指令、重复规则、执行位置，保存

### 管理任务

在「自动化任务」页面可以：

- 看所有任务、下次运行时间
- 「**暂停任务**」/「**恢复任务**」
- 「**立即执行**」：不等时间，马上跑一次试试
- 「**任务运行记录**」：看过去每次运行的结果

> [!WARNING]
> **电脑关机、或者 DSH 退出时，定时任务不会运行。** 退出 DSH 时，如果有定时任务，它会提醒你。
>
> 定时任务是**没人看着**自动跑的。只给它安全的、能撤回的事做；删除、发送消息、付款这类事**不要**放进定时任务。

## 3. 一条命令做完就退出（要用终端）

DSH 有一个 `headless`（无界面）模式：给它一个任务，做完打印结果，然后自动退出。适合放进你自己的脚本里。

在终端里，先 `cd` 进工作文件夹，然后：

```bash
npx @deepseek-ai/dsh headless "列出当前文件夹里所有的 txt 文件,并统计每个文件有多少行"
```

(如果你用桌面版，并且在应用菜单「**管理 dsh 命令…**」里安装了 `dsh` 命令，也可以直接用 `dsh headless "……"`。)

**应该看到：** DSH 做完任务，在终端里打印出最终答案，然后退出。

> [!TIP]
> 当前所在的文件夹就是它的工作区。所以一定要先 `cd` 到正确的文件夹。

## 4. 从 Python 里调用（要写代码）

DSH 提供官方 Python SDK（软件开发工具包，就是让你的 Python 程序能指挥 DSH 的工具包），包名 `deepseek-harness-sdk`。

适合想把 Agent 能力做进自己程序里的人。它的安装和示例比较长，而且还在快速变化，请直接看官方教程：

- 官方 Python SDK 入门：https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/python-sdk.zh.md

## 6. 常见问题

**问：定时任务到点了没运行？**
答：检查：① DSH 是不是开着；② 任务是不是「已暂停」；③ 时区对不对。

**问：`headless` 模式报错没有模型或认证失败？**
答：`headless` 用的是另一份配置（profile），第一次可能需要配置钥匙。可以先设置环境变量 `DEEPSEEK_API_KEY`（第 23 章教过）再运行。
