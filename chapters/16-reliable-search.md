# 第 16 章 实战三：让 AI 搜到靠谱资料，少说“胡话”

> **学完这一章，你能：**
> - 说清楚 AI 为什么会“说得很像真的，但其实是错的”
> - 知道解决这个问题要“搜索工具”和“调研方法”两样一起上
> - 装好一个“靠谱调研”skill，对比装之前、装之后的回答
> - 自己一眼认出 AI 批量写的垃圾网页
>
> **前置：** 第 13 章（会装 skill、会确认 skill 被调用）

## 1. 为什么要学这个

你可能遇到过：问 AI 一个问题，它回答得头头是道，还给了数字、给了“出处”——结果你一查，**数字是错的，出处根本不存在**。

这一章讲为什么会这样，以及怎么让 AI 少犯这种错。

## 2. 讲解：AI 为什么会说错

### 原因一：“幻觉”——不知道也会编

第 2 章讲过：大模型的本事是“**接话接得像**”。它不知道答案时，不会停下来说“我不知道”，而是接出一个**看起来最像答案**的答案。

专业名称叫**幻觉**(Hallucination)。最容易出幻觉的地方：**具体数字、日期、人名、链接、最新的消息。**

### 原因二：网上的 AI 垃圾内容越来越多

现在很多网站用 AI **批量生成**文章，为了赚流量、卖广告。这些文章常常：

- 内容不准，甚至是 AI 幻觉写出来的
- 互相抄，同一个错误被几十个网站重复
- 看起来很专业，但没有作者、没有日期、没有出处

于是出现了一个**恶性循环**：

```
AI 编了一个错的说法 → 被批量发到很多网站
        ↑                          ↓
 更多 AI 引用它 ←  另一个 AI 上网搜索,看到"很多网站都这么说",以为是真的
```

**错误越传越多，越传越“像真的”。** 这就是为什么让 AI“上网搜一下”也不一定能解决问题——它可能搜到的正是垃圾内容。

### 解决办法：两样一起上

打个比方：你要请人帮你调查一件事，需要两样东西：

| 需要什么 | 比喻 | 在 DSH 里是什么 |
|---|---|---|
| **搜得到** | 一个好的**搜索引擎** | DSH 的「网页搜索与获取」功能，或者接一个搜索 MCP(第 18 章) |
| **会判断** | 一个会挑来源、会核对的**调查员** | 一个“调研”skill |

只有搜索引擎，没有调查员 → 搜到什么信什么，垃圾也照单全收。
只有调查员，没有搜索引擎 → 想核对也查不到东西。

### 一个好的调研 skill 会让 AI 做到什么

本教程自带的 `reliable-research` skill 规定 AI 必须：

1. **不凭记忆回答**事实类问题，先搜索
2. **优先看一手来源**：官方网站、官方文档、政府公告、原始论文，少看转载和营销号
3. **交叉核对**：一个关键结论，要有 1 个官方来源，或 2 个互不转载的可靠来源
4. **反向搜索**：专门搜一下“相反的说法”，看有没有辟谣或更新
5. **看日期**：注明每个来源的日期，过时的要提醒
6. **每句话都标出处**，附上链接，让你能点进去核对
7. **找不到就说没找到**，不许编
8. **告诉你可信程度**：高、中、低

## 3. 跟着做

### 第一步：确认 DSH 能上网搜索

1. 打开「设置」→「**网页搜索与获取**」
2. 看「**网页搜索提供方**」和「**网页获取提供方**」有没有选上（一般选「自动选择」就行）

> [!TIP]
> 用 DeepSeek 提供的搜索时，**搜索是按次另外收费的**（价格见 DeepSeek 价格页），不算在 Token 里。一次调研可能搜十几次，心里有数。设置里的「**单次请求最多搜索次数**」可以限制次数。

### 第二步：先问一次（装 skill 之前），记下回答

新开一个会话，输入：

```
DeepSeek API 现在有哪些模型?每个模型输出 100 万 Token 多少钱?
```

把它的回答**复制保存**到一个文本文件里，命名为 `装之前.txt`。

### 第三步：安装 `reliable-research` skill

按第 13 章的方法，在 DSH 里输入：

```
请帮我安装一个 skill:
把 https://github.com/zhubing20011218-hub/agent-teaching 仓库里
skills/reliable-research 这个文件夹复制到 ~/.dsh/skills/reliable-research。
装好后列出里面的文件给我确认。
```

然后打开 [skills/reliable-research/SKILL.md](https://github.com/zhubing20011218-hub/agent-teaching/blob/main/skills/reliable-research/SKILL.md) 读一读。和 `ppt-polish` 一样，它只是一份写清楚的“规则”，没有脚本。

### 第四步：再问一次，对比

**新开一个会话**，输入：

```
/reliable-research DeepSeek API 现在有哪些模型?每个模型输出 100 万 Token 多少钱?
```

**应该看到：**

1. 「加载技能」→ `reliable-research`
2. AI 调用了好几次搜索、打开了几个网页
3. 回答按固定格式：**结论、详细说明、可信程度、来源列表、没找到的地方**
4. 来源里应该有 DeepSeek 官方的价格页(`api-docs.deepseek.com`)

保存为 `装之后.txt`，和 `装之前.txt` 对比：

| 对比项 | 装之前 | 装之后 |
|---|---|---|
| 有没有给出处链接？ | | |
| 出处是不是官方网站？ | | |
| 有没有写日期？ | | |
| 有没有说“可信程度”? | | |
| 价格和官方价格页一致吗？ | | |

### 第五步：亲手核对（最重要的一步）

**从来源列表里随便挑 2 个链接，点进去看：**

- 链接能打开吗？（打不开 → 可能是 AI 编的）
- 网页里真的有 AI 说的那句话、那个数字吗？
- 网页的日期是什么时候？

> [!WARNING]
> **skill 只能大大减少出错，不能保证 100% 正确。** AI 仍然可能看错、算错、漏掉更新。
> **涉及钱、健康、法律、合同的事，一定要自己点开官方原文核对**，不能只看 AI 的总结。

## 4. 自己练：一眼认出 AI 垃圾网页

以后你自己上网查资料时，也可以用这几条判断（出现 2 条以上，就要小心）：

- ❓ **没有作者、没有日期**
- 🔁 **内容空泛**，换着说法讲同一件事，没有具体数字、例子、出处
- 🗣️ **满篇套话**：“总之”“综上所述”“值得注意的是”“在当今快速发展的时代”
- 📋 **到处一样**：同一段话，在好几个网站上几乎一字不差
- 📢 **标题夸张**：“终极指南”“99% 的人不知道”，正文和标题对不上
- 💰 **广告比正文多**

## 7. 常见问题

**问：AI 没有搜索，直接凭记忆回答了？**
答：① 检查「网页搜索与获取」设置；② 用 `/reliable-research` 开头；③ 直接说“请先上网搜索，不要凭记忆回答”。

**问：AI 给的链接打不开？**
答：可能是 AI 编的，也可能是网站暂时打不开。告诉它：“第 2 个链接打不开，请重新核实这条结论，只用你实际打开过的网页。”

**问：调研很花钱吗？**
答：比普通聊天贵，因为要搜很多次、读很多网页。简单的事实问题，一般几毛钱；大型调研可能一两块。可以在设置里限制「单次请求最多搜索次数」。

**问：中文资料搜不到好的？**
答：很多一手资料是英文的。可以说“中文和英文资料都搜”，并让它把英文来源的要点翻译成中文。
