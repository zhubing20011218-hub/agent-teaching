# 第 2 章 大模型和 Agent 到底是什么

> **学完这一章，你能：**
> - 用自己的话说清楚“大模型”是什么
> - 说出“聊天机器人”和"Agent"的区别
> - 记住 Agent 的公式：**大脑 + 双手 + 反复做**
>
> **前置：** 无

## 1. 为什么要学这个

你可能已经用过 DeepSeek、豆包、ChatGPT 这类 AI 聊天软件。你问它“怎么把照片按日期改名”，它会告诉你一大段步骤。

可问题是：**它只告诉你怎么做，还是得你自己去做。**

有没有一种 AI，你说一句“帮我把照片按日期改名”，它就**自己动手**把照片改好？

有，这就是 **Agent**。这一章就讲它和普通聊天 AI 到底差在哪。

## 2. 讲解

### 大模型：一个超级会“接话”的程序

打个比方：想象一个人，他**读过网上几乎所有的文字**——书、新闻、网页、论坛、代码。读得太多了，以至于你说上半句，他总能接出最合适的下半句。

- 你说“床前明月光”，他接“疑是地上霜”
- 你说“帮我写一封请假条”，他接出一封完整的请假条
- 你说“Python 怎么读文件”，他接出一段代码

这就是**大模型**。它的本事就是**根据前面的文字，一个字一个字地往下接**，只不过接得特别好、特别像人。

专业名称叫 **大语言模型**，英文 **LLM**(Large Language Model)。DeepSeek、GPT、Claude 都是大模型的名字。

> [!TIP]
> 记住大模型的两个特点，后面会反复用到：
> 1. **它只会“输出文字”**。它没有手，不能自己打开你的文件。
> 2. **它不知道的事，也会接得像真的一样**。这叫“幻觉”，第 16 章专门讲怎么对付。

### 聊天机器人：大模型 + 一个聊天窗口

你平时用的 DeepSeek 网页版，就是给大模型套了一个聊天窗口。你打字，它回字。

它能**说**，但不能**做**：

| 你说 | 聊天机器人能做的 |
|---|---|
| “帮我把桌面照片按日期改名” | 告诉你步骤，或者写一段代码让你自己去运行 |
| “帮我看看这个文件夹里有什么” | 做不到，它看不到你的电脑 |
| “帮我做个 PPT” | 给你一份文字大纲，你自己复制到 PowerPoint 里 |

### Agent：会自己动手的 AI

**Agent**（中文常叫“智能体”）= 大模型 + 给它**一双手** + 让它**反复做直到做完**。

记住这个公式：

> **Agent = 大脑（模型）+ 双手（工具）+ 反复做（循环）**

- **大脑**：大模型，负责想“下一步该干什么”
- **双手**：叫做**工具**(tool)。比如“读文件”“改文件名”“上网搜索”“运行命令”。每个工具就是 AI 能做的一个动作
- **反复做**：做一步、看结果、再想下一步……一直到任务完成。专业名称叫**循环**(loop)

### 一个例子从头走到尾

你说：**"帮我把 `ai-练习/照片` 文件夹里的照片按拍摄日期改名。"**

Agent 内部大概是这样运转的：

```
第 1 圈
  想:我得先看看文件夹里有什么。
  做:用"列出文件"工具 → 看 照片 文件夹
  看结果:有 3 张照片:IMG_001.jpg、IMG_002.jpg、IMG_003.jpg

第 2 圈
  想:我需要知道每张照片的拍摄日期。
  做:用"读取照片信息"工具 → 读这 3 张照片
  看结果:分别是 2026-05-01、2026-05-03、2026-06-10

第 3 圈
  想:可以改名了。改名会动用户的文件,先问一下用户。
  问你:"我准备把 IMG_001.jpg 改成 2026-05-01.jpg……可以吗?"
  你:可以
  做:用"改文件名"工具 → 改 3 个文件

第 4 圈
  想:检查一下有没有改对。
  做:再用"列出文件"工具看一遍
  看结果:3 个文件都改好了

结束
  告诉你:"已经改好了 3 张照片,新名字是……"
```

注意第 3 圈：**动你文件之前，它会先问你**。这是好的 Agent 都有的安全设计，第 4 章和第 10 章会详细讲。

### 三者对比

| | 大模型 | 聊天机器人 | Agent |
|---|---|---|---|
| 比喻 | 一个很会接话的大脑 | 大脑 + 一张嘴 | 大脑 + 嘴 + 双手 + 会一步步把事做完 |
| 能说话吗 | 能 | 能 | 能 |
| 能动你的文件吗 | 不能 | 不能 | **能**（会先问你） |
| 能上网查资料吗 | 不能 | 有些能 | 能 |
| 遇到问题会自己调整吗 | 不会 | 不会 | **会**：这一步失败了，会换个办法再试 |

## 3. 跟着做

体会一下“能说但不能做”:

1. 打开 DeepSeek 网页版：https://chat.deepseek.com （用手机号登录）
2. 输入：`帮我看看我电脑桌面上的 ai-练习 文件夹里有什么文件`
3. 看它的回答

**应该看到：** 它会说它看不到你的电脑，然后教你怎么自己去看。

这就是聊天机器人的边界。学完第三部分，你会用 DeepSeek Harness 再问一次同样的问题——那时它会**真的去看**，然后告诉你答案。

## 5. 常见问题

**问：Agent 会不会乱删我的文件？**
答：好的 Agent 工具都有“审批”设计：删除、修改、运行命令之前会先问你。你还可以只给它一个文件夹的权限。第 10 章会教你怎么设置。

**问：Agent 和“AI 助手”“智能体”“AI 员工”是一回事吗？**
答：基本是一回事，只是叫法不同。本教程统一叫 Agent。

**问：Agent 比聊天机器人更聪明吗？**
答：不一定。大脑（模型）可以是同一个，区别是 Agent **多了双手、会一步步做**。就像同一个人，一个只能打电话指导你，一个能直接上门帮你干。
