# 附录 A 名词小词典

按拼音 / 字母顺序排列。每个词：**一句话大白话解释**，后面是第一次详细讲它的章节。

| 名词 | 英文 | 大白话解释 | 章节 |
|---|---|---|---|
| Agent / 智能体 | Agent | 会自己动手、一步步把事做完的 AI。= 大脑 + 双手 + 反复做 | 第 2 章 |
| AGENTS.md | — | 写给 AI 的“规章制度”文件，AI 每次都会看 | 第 20 章 |
| API | Application Programming Interface | 程序之间的“点菜窗口”：把请求递进去，把结果递出来 | 第 3 章 |
| API 地址 | Base URL / Endpoint | AI 服务在网上的“门牌号”。DSH 要的是去掉功能名之后的基础地址 | 第 8 章 |
| API 钥匙 | API Key | 调用 API 时证明“是你、从你账户扣钱”的一串字符。= 你的钱包 | 第 3、5 章 |
| API 协议 | API Protocol | 请求按哪种格式写：OpenAI、Anthropic、Gemini 等 | 第 3、8 章 |
| 版本号 | Version | 软件的第几版，比如 Python 3.12。太旧的版本，新工具可能跑不起来 | 第 1 章 |
| 倍率 | — | 中转站的价格系数：实际价格 ≈ 基础价格 × 倍率 | 第 9 章 |
| 插件 | Plugin | 给 DSH 本身增加或改变功能的“乐高积木” | 第 19 章 |
| 插话发送 | — | AI 正在干活时，马上打断它、插入你的新消息(`Cmd/Ctrl + Enter`) | 第 10 章 |
| 厂商渠道 | — | DSH 里的「第三方模型提供商」：从内置列表选厂商，一般不用填地址 | 第 8 章 |
| 大模型 | LLM(Large Language Model) | 读过海量文字、很会“接着往下写”的程序，Agent 的大脑 | 第 2 章 |
| 工具 | Tool | AI 能做的一个具体动作，比如读文件、搜索、运行命令 | 第 2 章 |
| 工具调用 | Tool Calling / Function Calling | AI 输出一张“申请单”，由 Harness 去真正执行工具 | 第 24 章 |
| 工作区 | Workspace | 你允许 AI 干活的那个文件夹 | 第 10 章 |
| 幻觉 | Hallucination | AI 不知道答案时，编一个看起来像真的答案 | 第 2、15 章 |
| 环境变量 | Environment Variable | 终端随身带的“小口袋”，可以放钥匙等值，不用写进代码 | 第 23 章 |
| 会话 | Session | 一段完整的对话。建议一件事开一个 | 第 10 章 |
| 加载技能 | — | 对话里显示 AI 拿出了哪本“说明书”(skill) | 第 12 章 |
| 镜像源 | Mirror | 国外下载服务器在国内的副本，下载更快 | 第 1 章 |
| 开源 | Open Source | 代码公开，大家可以免费看、用、改（要遵守许可证） | 第 4 章 |
| 令牌 | Token | 中转站后台对 API 钥匙的叫法。和计费单位 Token 不是一回事 | 第 9 章 |
| 路径 | Path | 文件在电脑里的“家庭住址”，比如 `~/Desktop/ai-练习` | 第 1 章 |
| 内部网关 | Internal Gateway | 学校、公司自己搭的中转站，只能在单位网络里用 | 第 9 章 |
| 渠道 / 提供商 | Channel / Provider | 一个能调用 AI 的来源。中转站后台叫“渠道”，DSH 里叫“提供商” | 第 8 章 |
| 权限模式 | Permission Mode | AI 不问你就能做多少事：仅可查看 / 工作区内修改 / 完全权限 | 第 10 章 |
| 上下文窗口 | Context Window | AI 一次最多能“读”多少内容 | 第 3 章 |
| 审批 | Approval | AI 要做越界的事时停下来问你：拒绝 / 允许一次 / 始终允许 | 第 10 章 |
| 定时任务 | Schedule | 让 DSH 按时间自动做事，在「自动化任务」里管理 | 第 17 章 |
| 提示词 | Prompt | 你给 AI 的指令和说明 | 第 23 章 |
| 提示词注入 | Prompt Injection | 藏在网页、文件里骗 AI 的指令 | 第 22 章 |
| 头部信息 | Frontmatter | `SKILL.md` 最上面两条 `---` 之间的“标签”，写 `name` 和 `description` | 第 11 章 |
| 循环 | Loop | Agent 一圈一圈“想 → 做 → 看结果”直到完成 | 第 2、24 章 |
| 压缩 | Compact | 聊太长时，把前面的内容总结成一小段，省钱、不糊涂 | 第 10 章 |
| 运行环境 | Environment | 程序要靠的“底座软件”和它们的版本，比如 Python、Node.js。像做菜要先有厨房 | 第 1 章 |
| 终端 | Terminal / PowerShell | 用打字指挥电脑的窗口 | 第 1 章 |
| 中转站 | Relay / Proxy | AI 的“代购”：替你把请求转给 AI 公司，按用量扣你的余额。你的内容会经过它 | 第 9 章 |
| 子智能体 | Subagent | 主智能体分出去、并行干活的“助理” | 第 20 章 |
| 自定义渠道 | — | DSH 里的「自定义模型 API」：自己填地址、协议、钥匙和模型 | 第 8 章 |
| Token | Token | AI 计费的单位，大致可以理解成“字数” | 第 3 章 |
| DSH | DeepSeek Harness | DeepSeek 开源的 Agent 管家程序，本教程的主角 | 第 4 章 |
| git | git | 文件的“存档”工具，可以随时回到以前的样子 | 第 22 章 |
| GitHub | GitHub | 存放 git 存档和开源项目的网站 | 第 22 章 |
| Harness | Harness | 驾驭大模型的程序：提供工具、跑循环、管审批和记忆 | 第 4 章 |
| JSON / YAML | — | 两种写配置的文本格式。YAML 只能用空格缩进 | 第 1、18 章 |
| MCP | Model Context Protocol | AI 工具的“万能插座”标准 | 第 18 章 |
| Node.js | — | 很多程序运行需要的“底座软件” | 第 6 章 |
| npm | npm | Node.js 自带的“应用商店”，用来装 Node.js 的工具包 | 第 1 章 |
| OpenAI 兼容 | OpenAI-compatible | 用和 OpenAI 一样的“菜单格式”，换一家 AI 很方便 | 第 3 章 |
| profile | — | DSH 的一套配置。桌面版叫 `desktop`，网页版叫 `web` | 第 18、19 章 |
| pip | pip | Python 自带的“应用商店”，用来装 Python 的工具包 | 第 1 章 |
| Provider ID | — | 给自定义渠道起的代号，小写字母开头，建好后不能改 | 第 8 章 |
| Python | Python | 一种很流行的编程语言；处理 Excel、PDF、数据的 skill 常要用它 | 第 1 章 |
| Skill / 技能 | Skill | 给 AI 的“说明书”，需要时才拿出来看 | 第 11 章 |
| `~` | — | 你的用户文件夹的简写 | 第 1 章 |
