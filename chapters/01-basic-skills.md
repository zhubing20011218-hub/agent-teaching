# 第 1 章 四个必备小技能

> **学完这一章，你能：**
> - 打开“终端”，输入一条命令，看懂电脑的回答
> - 找到一个文件夹的“路径”（它在电脑里的地址）
> - 用合适的软件打开和编辑“文本文件”
> - 知道什么是“运行环境”，会查 Python、Node.js 装没装、是什么版本
>
> **前置：** 第 0 章

## 1. 为什么要学这个

后面的章节里，偶尔会让你“在终端里输入一条命令”，或者“把文件放进某个文件夹”。

如果你从来没做过，第一次会有点慌。这一章花一个小时，把这四件小事一次学会。**学会之后，后面每一章都会轻松很多。**

## 2. 小技能一：终端

### 终端是什么

打个比方：平时你用鼠标“点”来指挥电脑；**终端就是一个用“打字”来指挥电脑的窗口。**

你打一行字（叫**命令**），按回车，电脑就照着做，然后把结果用文字回给你。

专业名称：Mac 上叫“终端”(Terminal),Windows 上常用的是 "PowerShell"。本教程统一叫它**终端**。

> [!TIP]
> 终端看起来像黑客电影里的黑窗口，但它一点都不危险——只要你**只输入教程里给你的命令**。

### 跟着做：打开终端

**Mac:**

1. 同时按 `⌘ + 空格`，屏幕中间会弹出一个搜索框（叫“聚焦搜索”）
2. 输入 `终端`(或者 `terminal`)
3. 按回车

**应该看到：** 一个白色或黑色的窗口，里面有一行字，结尾是 `%` 或 `$`，后面有一个闪烁的光标。

**Windows:**

1. 点屏幕左下角的“开始”按钮（Windows 图标）
2. 输入 `PowerShell`
3. 点搜索结果里的"Windows PowerShell"

**应该看到：** 一个蓝色或黑色的窗口，里面有一行以 `PS C:\Users\你的名字>` 开头的字。

### 跟着做：输入第一条命令

1. 点一下终端窗口，确保光标在里面闪
2. 输入下面这行字（可以直接复制粘贴）：

```bash
echo 你好,终端
```

3. 按回车

**应该看到：** 下一行出现 `你好,终端`。

这条命令的意思是“把后面的字原样说一遍”。恭喜，你已经用终端指挥了一次电脑！

### 在终端里复制粘贴

| 操作 | Mac | Windows PowerShell |
|---|---|---|
| 粘贴 | `⌘ + V` | `Ctrl + V` 或点鼠标右键 |
| 复制终端里的字 | 用鼠标选中，`⌘ + C` | 用鼠标选中，`Ctrl + C`(没有选中文字时按 `Ctrl + C` 是“停止”，见下面) |

### 三个最常用的按键

| 按键 | 作用 |
|---|---|
| `回车` | 执行你刚输入的命令 |
| `Ctrl + C` | **紧急停止**：正在运行的命令卡住了、不想等了，按它 |
| `↑`（上箭头） | 调出上一条命令，不用重新打 |

### 怎么判断命令成功了没有

- **成功**：一般会显示一些结果，然后又出现那个 `%`、`$` 或 `>`，等你输入下一条
- **失败**：一般会出现 `error`、`not found`、`错误`、`找不到` 这类字

> [!WARNING]
> 失败了也不用怕：**把整段红字或报错文字复制下来**，发给 AI 问“这是什么意思、怎么解决”，一般都能找到答案。

## 3. 小技能二：文件夹路径

### 路径是什么

打个比方：**路径就是文件在电脑里的“家庭住址”。**

就像“广东省 → 深圳市 → 南山区 → 某某路 1 号”一样，电脑里的文件也是一层一层放的：

- Mac:`/Users/你的名字/Desktop/ai-练习`
- Windows:`C:\Users\你的名字\Desktop\ai-练习`

它的意思是：“用户文件夹 → 你的名字 → 桌面 → ai-练习”。

> [!TIP]
> Mac 用 `/` 分隔每一层，Windows 用 `\` 分隔。

### 跟着做：找到 `ai-练习` 文件夹的路径

(第 0 章让你在桌面建了 `ai-练习` 文件夹，没建的话现在建一个。)

**Mac:**

1. 打开“访达”(Finder)，找到桌面上的 `ai-练习` 文件夹
2. **按住 `Option` 键**，在文件夹上点右键
3. 选择“将 'ai-练习' 拷贝为路径名称”

**Windows:**

1. 打开“文件资源管理器”，找到桌面上的 `ai-练习` 文件夹
2. **按住 `Shift` 键**，在文件夹上点右键
3. 选择“复制为路径”

**应该看到：** 看起来什么都没发生，但路径已经被复制了。打开“备忘录”或“记事本”，粘贴一下，就能看到这串地址。

> [!TIP]
> 还有个更省事的办法：在终端里输入 `cd `（注意 cd 后面有个空格），然后**把文件夹直接拖进终端窗口**，路径会自动出现。

### `~` 是什么

后面会经常看到 `~/.dsh` 这种写法。`~` 是“**你的用户文件夹**”的简写：

- Mac:`~` = `/Users/你的名字`
- Windows:`~` = `C:\Users\你的名字`

所以 `~/.dsh` 就是"你的用户文件夹里，一个叫 `.dsh` 的文件夹"。

### 名字以 `.` 开头的文件夹为什么看不到

名字以点开头的文件夹(比如 `.dsh`)是**隐藏文件夹**，平时默认不显示，防止被误删。

想看到它们：

- **Mac**：在访达里按 `⌘ + Shift + .`（句号），再按一次就重新隐藏
- **Windows**：文件资源管理器 → 顶部“查看” → “显示” → 勾选“隐藏的项目”

## 4. 小技能三：文本文件

### 文本文件是什么

**只有文字、没有格式**（没有字号、颜色、图片）的文件，就是文本文件。

后面会遇到这几种，它们**本质上都是文本文件**，只是后缀名不同：

| 后缀 | 是什么 | 例子 |
|---|---|---|
| `.txt` | 普通文本 | `笔记.txt` |
| `.md` | Markdown，一种用简单符号排版的文本(比如 `#` 表示标题) | `SKILL.md` |
| `.yml` / `.yaml` | 配置文件，写“设置项：值” | `cordis.patch.yml` |
| `.json` | 另一种配置文件格式，到处是 `{}` 和 `""` | `package.json` |

> [!WARNING]
> **不要用 Word 打开它们**。Word 会偷偷加入格式，把文件弄坏。

### 用什么软件打开

推荐安装一个免费的代码编辑器 **VS Code**(Visual Studio Code)。它打开文本文件最方便，还会用颜色帮你标出格式错误。

- 下载：https://code.visualstudio.com （选你的系统，下载后像普通软件一样安装）

不想装也可以：

- **Mac**：用“文本编辑”，但要先在菜单“格式”里选“制作纯文本”
- **Windows**：用“记事本”

### 跟着做：新建一个文本文件

1. 打开 VS Code
2. 菜单“文件” → “新建文本文件”
3. 输入：`我的第一个文本文件`
4. 菜单“文件” → “保存”，保存到 `ai-练习` 文件夹，文件名写 `test.md`

**应该看到：** `ai-练习` 文件夹里多了一个 `test.md` 文件。

## 5. 小技能四：认识“运行环境”

### 运行环境是什么

做菜要先有厨房：灶台、锅、调料。菜谱写得再好，厨房里没有锅也做不出来。

电脑也一样。很多程序和 skill，要靠电脑里**先装好的“底座软件”**才能运行。这些底座软件，加上它们的**版本**，就叫**运行环境**。

最常见的两个底座：

| 名字 | 大白话 | 谁会用到它 |
|---|---|---|
| **Python** | 一种很流行的编程语言的“运行器” | 处理 Excel、PDF、数据分析的 skill；AI 帮你写的小脚本 |
| **Node.js** | 另一种编程语言（JavaScript）的“运行器” | 做 PPT、Word 的 skill；DSH 网页版 |

它们各自带一个“应用商店”，用来装更小的工具包：

| 名字 | 是谁的 | 装工具包的命令长这样 |
|---|---|---|
| **pip** | Python 的 | `pip install openpyxl` |
| **npm** | Node.js 的 | `npm install pptxgenjs` |

还有一些独立软件也算环境的一部分，比如 **LibreOffice**（让 AI 把 PPT、Excel 转成 PDF 自己检查）、**ffmpeg**（处理视频）。

### 为什么要管“版本”

版本号就像手机系统的版本，比如 `Python 3.12.4`、`Node.js v22.11.0`。

- **太旧的版本**，新的工具包可能装不上、跑不起来
- 一般记住两条就够：**Python 要 3.10 以上，Node.js 要 18 以上**

### 跟着做：查一查你的电脑

打开终端，**一条一条**输入下面的命令，每条输完按回车：

```bash
python3 --version
```

```bash
node --version
```

Windows 上第一条换成：

```bash
python --version
```

**应该看到：** 类似 `Python 3.12.4`、`v22.11.0` 这样的版本号。

**如果看到** `command not found`（Mac）或“不是内部或外部命令”（Windows）：说明**没装**。这很正常，用到的时候再装就行。

**Mac 第一次输入 `python3`** 可能会弹出窗口，问要不要安装“命令行开发者工具”。点「安装」就行，这是苹果官方的工具，装好后就有 Python 3 了。

### 让 AI 帮你检查（更省事）

在 DSH 里新建一个会话，权限选「仅可查看」，发：

```text
帮我检查这台电脑的运行环境：操作系统和版本、Python、pip、Node.js、npm、Git、LibreOffice、ffmpeg。
每一项告诉我：装了没有、版本号、够不够用（Python 要 3.10 以上，Node.js 要 18 以上）。
只检查，不要安装任何东西。用表格列给我。
```

也可以装本教程自带的 `env-check` skill，以后说一句“检查环境”就行。

### 缺了怎么装

| 要装的 | 怎么装 | 注意 |
|---|---|---|
| Python | 去官网 https://www.python.org/downloads/ 下载安装包，双击安装 | **Windows 安装时一定勾上 “Add python.exe to PATH”** |
| Node.js | 去官网 https://nodejs.org 下载 **LTS（长期支持）** 版安装包，双击安装 | 装完**关掉终端再重新打开**，新装的才认得 |
| LibreOffice | 官网 https://www.libreoffice.org/download/download-libreoffice/ | 装完打开一次再关掉 |
| 工具包（pip / npm） | 让 AI 在工作区里装，它会先告诉你命令 | 看清命令再点「允许一次」 |

> [!WARNING]
> **安装软件的规矩：**
> - 安装包**只从官网下载**，不要用来路不明的网盘、破解版
> - 安装时要输入**电脑开机密码**的，你自己输；**不要把密码发给 AI**
> - AI 要运行安装命令时，先让它说清楚这条命令做什么。看到 `sudo`（要管理员权限）、`curl ... | sh`（从网上下载并直接运行）这类命令，问清楚再允许

### 国内下载太慢怎么办

pip、npm 默认从国外服务器下载，可能很慢。可以让 AI 用国内镜像（官方内容的国内副本）：

```text
用国内镜像安装：pip 用清华源 https://pypi.tuna.tsinghua.edu.cn/simple ，npm 用 https://registry.npmmirror.com 。
只在这次安装时使用，不要修改我电脑的全局设置。
```

## 7. 常见问题

**问：我在终端里打字没反应？**
答：先用鼠标点一下终端窗口里面，让光标在里面闪。

**问：命令输错了，怎么删？**
答：按回车之前，用 `退格键` 删就行，和普通打字一样。如果已经按了回车，报个错也没关系，重新输入正确的就好。

**问：终端里出现 `Password:` 让我输密码？**
答：这是要你输入**电脑的开机密码**。输入时屏幕上**不会显示任何字**（连星号都没有），这是正常的，输完按回车即可。只有教程明确说“会让你输密码”的命令才输；不确定就先按 `Ctrl + C` 停止。

**问：Windows 上运行命令，提示“禁止运行脚本”?**
答：后面安装软件时可能会遇到，到时候对应章节会给解决办法。现在先不用管。

**问：明明装了 Python / Node.js，终端还是说找不到？**
答：先**关掉终端再重新打开**。还不行：Windows 上重新运行 Python 安装包，选「Modify」，勾上「Add Python to environment variables」；Mac 上试试 `python3` 而不是 `python`。

**问：电脑里装了好几个 Python，乱了怎么办？**
答：新手不用管，能用就行。真遇到“装了包却说找不到”，把报错发给 AI，让它帮你看用的是哪一个。
