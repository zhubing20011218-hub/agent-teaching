# 第 9 章 把钥匙填进 DSH

> **学完这一章,你能:**
> - 让 DSH 连上 DeepSeek,发出第一句话
> - 知道"登录账号"和"添加 API Key"的区别
> - 添加其他家的 AI 或"中转站",选择默认模型
>
> **前置:** 第 5 章(有 API 钥匙)、第 8 章(装好 DSH)

## 1. 为什么要学这个

DSH 是"管家",DeepSeek 是"大脑"。这一章把它们**接起来**——就是第 3 章讲的,给管家一把能打通"点菜窗口"的钥匙。

## 2. 讲解:两种接法

桌面版欢迎页上有两个按钮:

| 按钮 | 意思 | 什么时候选 |
|---|---|---|
| 「**登录**」 | 登录你的 **DeepSeek 账号**,用账号里的额度 | 你不想自己管理钥匙,想最省事 |
| 「**添加 API Key**」 | 填你在第 5 章申请的**钥匙** | ✅ **本教程推荐**:用量和花费都在开放平台看得清清楚楚,接其他工具也用同一套 |

两种都可以,以后也能在设置里改。本章按"添加 API Key"来讲。

## 3. 跟着做

### 方法一:在欢迎页添加(桌面版第一次打开时)

1. 在欢迎页点「**添加 API Key**」
2. 页面变成「添加一个 API Key 开始使用」
3. 在「**输入 API 密钥**」框里,粘贴你的钥匙(`sk-` 开头那串)
4. 点「**保存并继续**」

**应该看到:** 进入 DSH 的主界面。

📷 截图待补:添加 API Key 页面(钥匙部分打码)

### 方法二:在设置里添加(网页版,或者之后想改)

1. 打开「**设置**」(一般在左下角)
2. 选「**模型**」
3. 找到 **DeepSeek** 卡片,在 API 密钥的框里粘贴钥匙
4. 点「**保存**」

**应该看到:** 保存成功,DeepSeek 卡片显示已配置。**不用重启**,马上就能用。

📷 截图待补:设置 → 模型 页面

### 为什么保存后看不到完整的钥匙

保存之后,框里只显示钥匙开头和结尾几个字符,中间是点点点。这是**故意的**:

- 防止你截图时不小心泄露
- 防止别人坐到你电脑前偷看

钥匙存在你电脑的 `~/.dsh/.credentials.yaml` 里。想换钥匙,直接在框里粘贴新的,点保存就行。

### 第三步:说第一句话

1. 主界面中间有个输入框,写着"发消息或创建任务……"
2. 如果提示「**选择一个工作区开始**」,先点「**选择工作区**」,选第 0 章建的 `ai-练习` 文件夹(下一章会详细讲工作区)
3. 输入:`你好,用一句话介绍你自己`
4. 按回车

**应该看到:** AI 回复了一句自我介绍。🎉 **你的 Agent 连通了!**

## 4. 选择默认模型

输入框附近有一个**模型选择器**,显示当前用的是哪个模型。点它可以切换。

DeepSeek 现在主要有两个(2026-11 的情况):

| 模型 | 特点 | 推荐 |
|---|---|---|
| `deepseek-flash` | 快、便宜 | ✅ 日常和学习用它 |
| `deepseek-v4-pro` | 更聪明,贵 3~4 倍 | 复杂任务、写长文档、Flash 做不好时再换 |

选好的模型会成为**新会话的默认模型**。已经开始的会话保持它原来用的模型。

> 💡 DeepSeek 发布新模型时,DSH 会自动更新模型列表(大约每 10 分钟检查一次),一般不用你手动加。

## 5. 进阶:接其他家的 AI 或"中转站"

### 接其他 AI 公司(Kimi、GLM、Claude、GPT……)

1. 「设置」→「模型」→「**添加模型提供商**」
2. 默认就在「**第三方模型提供商**」,从列表里选一家(比如 Kimi 对应 `moonshotai`,智谱 GLM 对应 `zai`)
3. 粘贴**那一家**的 API 钥匙(要去那家的官网申请,和 DeepSeek 的钥匙不通用)
4. 保存

### 接"中转站"、公司网关、自己搭的服务

**中转站**:有些服务商把多家 AI 打包在一起卖,给你一个地址和一把钥匙。

1. 「设置」→「模型」→「添加模型提供商」→ 切换到「**自定义模型 API**」
2. 填写:
   - **Provider ID**:给它起个英文小写名字,比如 `myproxy`。⚠️ **以后不能改**,想清楚再填
   - **API 地址**(基础 URL):服务商给你的地址
   - **API 协议**:问服务商用的是哪种。最常见的是 **OpenAI Chat Completions**(第 3 章讲过这几种格式)
   - **API 密钥**:服务商给你的钥匙
3. 在「模型目录」里点「**获取可用模型**」,勾选要用的模型;获取不到就手动填模型名
4. 保存

> ⚠️ **中转站有风险:** 你发给 AI 的所有内容(包括 AI 读过的你的文件)都会经过中转站。只用你信任的服务商,不要让 AI 读敏感文件。

## 7. 常见问题

**问:发消息后报错"认证失败"或 401?**
答:钥匙不对。去开放平台确认钥匙没被删除;重新复制一遍,注意不要多复制空格。

**问:报错"余额不足"或 402?**
答:去 https://platform.deepseek.com 充值。充完马上就能用,不用重新填钥匙。

**问:输入框是灰的,打不了字?**
答:还没选工作区。点「选择工作区」选一个文件夹。

**问:我点了"登录",想改成用 API Key?**
答:「设置」→「模型」里添加 API Key 即可。「设置」→「**账号与余额**」里可以看登录状态,也可以退出登录。

**问:Provider ID 填错了怎么办?**
答:Provider ID 不能改。新建一个正确的,再把错的删掉。
