# 第 22 章 综合实战

> **学完这一章，你能：**
> - 把前面学的工作区、skill、MCP、子智能体、定时任务**组合起来**，完成真实的工作
> - 学会把一个大任务拆成几步，每一步都检查
>
> **前置：** 主线第 0–20 章

## 1. 为什么要学这个

前面每一章只练一样本事。真实工作往往要**几样一起用**。这一章给你三个完整的项目，选一个和你工作最接近的做。

**做项目的通用方法（每个项目都用）：**

1. **建一个专用文件夹**作为工作区
2. **先要计划**：“先给我看计划，我确认后再做”
3. **分步做，每步检查**：不要一句话让 AI 做完全部
4. **重要的结果自己核对**
5. **满意的做法写成 skill**，下次直接用

## 2. 项目 A：每天自动整理资料、写日报

**用到：** 工作区、定时任务（第 11 章）、写 skill（第 17 章）

**目标：** 每天下班前，AI 自动把今天放进“收件箱”文件夹的资料分类归档，并写一份日报。

### 步骤

1. 建文件夹 `ai-练习/日报项目`，里面建 `收件箱`、`归档`、`日报` 三个子文件夹
2. 往 `收件箱` 里放几份资料（文章、笔记、截图）
3. 手动跑一次，把流程调顺：

```
请处理 收件箱 里的所有文件:
1. 按主题分类,移动到 归档/<主题名>/ 里
2. 每份资料用一两句话总结
3. 在 日报/ 里新建今天日期命名的文件(比如 2026-11-17.md),
   写一份日报:今天收到了哪些资料、各自讲什么、有哪些值得跟进的
先给我看分类计划,我确认后再移动。
```

4. 调到满意后，把这套做法写成一个 skill，叫 `daily-report`
5. 创建定时任务：

```
每个工作日 Asia/Shanghai 时区 17:30,用 daily-report skill 处理 日报项目/收件箱,
分类方案不确定的文件留在收件箱里,不要移动,在日报里列出来。
```

> [!WARNING]
> 定时任务没人看着，所以第 5 步改成了“不确定的不要动”。**自动化任务一定要保守。**

## 3. 项目 B：做汇报，一条龙

**用到：** 调研 skill（第 16 章）、搜索 MCP（第 18 章）、子智能体（第 20 章）、PPT skill（第 14、15 章）

**目标：** 给一个主题，AI 完成“调研 → 大纲 → PPT → 讲稿”。

### 步骤

1. 建文件夹 `ai-练习/汇报项目`
2. **调研**（这一步最重要，资料错了后面全错）：

```
/reliable-research 我要做一个关于"<你的主题>"的 10 分钟汇报,给<听众>听。
请用子智能体分成 3 个方向并行调研:<方向一>、<方向二>、<方向三>。
每个结论都要有来源。汇总后保存为 调研报告.md。
```

3. **自己核对**调研报告：点开几个关键来源看看
4. **大纲**：

```
根据 调研报告.md 写一个 8 页 PPT 的大纲,每页标题直接写结论。
只用调研报告里有来源的内容,不要加新的数字。保存为 大纲.md。
```

5. **PPT**:

```
/pptx 按 大纲.md 做 PPT,用 my-ppt-style 的风格,
每页加演讲备注,保存为 汇报.pptx。做完转成图片自己检查一遍。
```

6. **优化和讲稿**：

```
用 ppt-polish 检查 汇报.pptx,先给我诊断表。
确认修改后,另存为 汇报_终版.pptx,并把所有演讲备注整理成一份 讲稿.md。
```

## 4. 项目 C：电商运营助手

**用到：** 工作区、`@` 文件、写 skill、调研 skill

**目标：** 批量写商品文案、整理销售表格。

### 步骤

1. 建文件夹 `ai-练习/电商项目`，放一份商品表格(比如 `商品.xlsx`，有商品名、规格、价格、卖点)

> [!TIP]
> 处理 Excel 表格，可以先装一个表格类 skill，比如 [anthropics/skills 里的 xlsx](https://github.com/anthropics/skills/tree/main/skills/xlsx)(方法和第 14 章装 `pptx` 一样)。

2. **先试一个**：

```
@商品.xlsx 读一下这个表格,先给第一个商品写一段 100 字左右的商品描述,
语气<活泼/专业>,突出卖点,不要用"最好""第一"这类极限词。
```

3. 调到满意后，把要求写成 skill `product-copy`（写清：字数、语气、禁用词、格式）
4. **批量**：

```
用 product-copy skill 给 商品.xlsx 里的所有商品写描述,
写进表格新的一列"商品描述",另存为 商品_带描述.xlsx。
```

5. **抽查**：随机挑 5 个商品的描述，检查有没有写错规格、编造功能

> [!WARNING]
> 商品文案里的**规格、功效、认证**等信息，必须来自你给的表格。AI 编造的功效可能违反平台规则甚至法律。
