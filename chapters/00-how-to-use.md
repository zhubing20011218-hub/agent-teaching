# 第 0 章 怎么用这份教程

> **学完这一章，你能：**
> - 知道这份教程适合你吗、学完能做到什么
> - 知道该按什么顺序学，哪些章可以跳过
> - 准备好学习要用的东西
>
> **前置：** 无

## 1. 这份教程写给谁

写给**完全没有编程基础**的人。

只要你会这几件事，就能学完主线：

- 会用电脑上网、下载和安装软件
- 会复制、粘贴(`Ctrl+C` / `Ctrl+V`,Mac 上是 `⌘+C` / `⌘+V`)
- 会打字

不需要会写代码。不需要懂英文。遇到的每个新词，教程都会先打个比方，再用大白话解释。

## 2. 学完你能做到什么

学完主线，你可以让 AI **真的动手帮你干活**，而不只是陪你聊天。比如：

- 把一个乱七八糟的文件夹整理好
- 给你做一份 PPT，或者把你已有的 PPT 改得更好看
- 帮你上网查资料，并且每句话都附上出处，让你能核对
- 按你自己的习惯，教会 AI 新本事（这叫 skill，第四部分会讲）

## 3. 路线图

教程分成 7 个部分，一共 24 章，外加 4 个附录。

| 部分 | 学什么 | 大概要多久 |
|---|---|---|
| 第 0 部分 开始之前 | 本章 + 三个必备小技能 | 1 小时 |
| 第一部分 弄懂概念 | 大模型、Agent、API、Harness 是什么 | 1 小时 |
| 第二部分 拿到钥匙 | 申请 DeepSeek 的 API 钥匙 | 半小时 |
| 第三部分 用上 DSH | 安装 DeepSeek Harness，让它帮你干活 | 2 小时 |
| 第四部分 Skill | 教 AI 新本事：做 PPT、美化 PPT、搜靠谱资料 | 3 小时 |
| 第五部分 进阶定制 | 接更多工具、装插件、定制你的 AI | 2 小时 |
| 第六部分 实战与安全 | 综合练习、安全、怎么少花钱 | 2 小时 |

### 🟢 主线和 🟡 选修

- 🟢 **主线**：不用写代码，所有人都要学。
- 🟡 **选修**：要写一点代码，适合想弄懂原理、或者想深入定制的人。**跳过选修，完全不影响学主线。**

第一次学，建议**只学 🟢 主线**，从头学到尾。以后有兴趣了再回来看 🟡 选修。

## 4. 每一章长什么样

每一章都是同样的结构，习惯了之后读起来很快：

1. **学完这一章，你能……**：先告诉你这章的目标
2. **为什么要学这个**：用一个生活中的场景引入
3. **讲解**：先打比方，再说大白话，最后才说专业名称
4. **跟着做**：一步一步，每一步都告诉你“做完应该看到什么”
5. **自己检查**：几个问题，确认你真的学会了
6. **常见问题**：最常遇到的坑和解决办法
7. **想了解更多**：官方资料的链接

## 5. 开始之前要准备什么

| 要准备的 | 说明 |
|---|---|
| 一台电脑 | Mac(建议 M 系列芯片)或 Windows 10/11 都可以 |
| 能上网 | 安装软件、调用 AI 都需要联网 |
| 一张能付款的卡，或者支付宝 / 微信 | DeepSeek 的 API 是按用量收费的，第 5 章会教你充值。学完整个教程，一般**几块钱人民币**就够了 |
| 一个文件夹 | 在桌面新建一个文件夹，名字叫 `ai-练习`。后面所有练习都在这个文件夹里做，不会碰到你的其他文件 |

## 6. 关于“版本”和“内容过时”

这份教程会持续更新。但 AI 工具变化很快，有时你看到的界面可能和教程写的不一样。

所以每一章开头都有两行小字：

- **验证版本（verified_with）**：这一章是用哪个版本的软件检查过的
- **验证日期（last_checked）**：哪一天检查的

如果你看到的画面和教程不一样：

1. 先看看你的软件版本是不是比教程写的新
2. 打开章节末尾“想了解更多”里的官方链接，官方文档一般是最新的
3. 欢迎到本教程的 GitHub 页面提一个 Issue(问题反馈)，告诉我们哪里不一样
