# 第 3 章 API 是什么

> **学完这一章，你能：**
> - 用“点菜窗口”的比喻讲清楚 API
> - 知道 API 钥匙（API Key）是什么、为什么它就是你的钱包
> - 知道 Token 是什么、AI 是怎么收费的
> - 知道“OpenAI 兼容”是什么意思
>
> **前置：** 第 2 章

## 1. 为什么要学这个

上一章说过，Agent 的“大脑”是大模型。可大模型在 DeepSeek 公司的服务器上，不在你的电脑里。

那 Agent 程序是怎么“用上”这个大脑的？答案是：**通过 API。**

后面你会经常看到"API""API Key""Token"“OpenAI 兼容”这些词。这一章把它们一次讲清楚。

## 2. 讲解

### API：餐厅的点菜窗口

想象一家餐厅：

- **厨房**：真正做菜的地方。你进不去，也不需要知道里面怎么做
- **点菜窗口**：你把写好的菜单从窗口递进去，过一会儿，菜从窗口递出来
- **规矩**：菜单必须按餐厅规定的格式写，不然厨房看不懂

API 就是这个**点菜窗口**：

| 餐厅 | AI |
|---|---|
| 厨房 | DeepSeek 服务器上的大模型 |
| 点菜窗口 | API |
| 菜单 | 你发过去的**请求**（里面写着你要问的话） |
| 端出来的菜 | AI 发回来的**回复** |
| 菜单格式的规矩 | API 的**格式要求** |

专业名称：**API**（Application Programming Interface，应用程序编程接口）。你不用记英文全称，记住“点菜窗口”就够了。

### 一次 API 调用里有什么

每次“点菜”，都要写清楚 4 样东西：

1. **窗口地址**：去哪个窗口点。DeepSeek 的是 `https://api.deepseek.com`
2. **钥匙**：证明你是谁、从谁的账户扣钱（下面细讲）
3. **用哪个模型**：比如 `deepseek-flash`（快、便宜）或 `deepseek-v4-pro`（更强、更贵）
4. **对话内容**：你要说的话，还有之前聊过的内容

然后窗口会递回来：**AI 的回答**，以及**这次用了多少 Token**（决定扣多少钱）。

> [!TIP]
> 网页版 DeepSeek 背后其实也在做同样的事，只是网页帮你把这些都填好了。

### API 钥匙：证明“是你在点菜”

**API 钥匙**(API Key)是一长串字母和数字，大概长这样：

```
sk-a1b2c3d4e5f6……(一共几十个字符)
```

每次调用 API 都要带上它。它的作用有两个：

1. **证明身份**：DeepSeek 看到钥匙，就知道“这是某某的账户”
2. **扣钱**：这次调用的费用，从这把钥匙对应的账户里扣

> [!WARNING]
> **API 钥匙 = 你的钱包。**
> 谁拿到你的钥匙，谁就能用你的钱调用 AI，一直用到你余额花光。所以：
> - **不要**发到微信群、QQ 群、论坛
> - **不要**截图分享（截图里有钥匙也不行）
> - **不要**写进要上传到网上的文件里（比如 GitHub）
> - **不要**告诉“客服”或任何人，正规平台不会找你要钥匙
>
> 万一泄露了：马上去 DeepSeek 平台**删除这把钥匙**，再新建一把。第 5 章会教具体怎么做。

### Token:AI 收费的单位

AI 不按“次”收费，而是按 **Token** 收费。

**Token 可以粗略理解成“字数”**:AI 读和写文字时，会把文字切成一小块一小块，每一块就是一个 Token。

- 1 个中文字 ≈ 0.6 个 Token
- 1 个英文字母 ≈ 0.3 个 Token

（这是 DeepSeek 官方给的粗略估算，实际以每次调用返回的数字为准。）

收费分两部分：

- **输入**：你发过去的文字（包括之前的聊天记录）
- **输出**：AI 写回来的文字

**DeepSeek 的价格**（2026-11-17 查阅官方价格页，单位：元 / 每 100 万 Token）：

| 模型 | 输入 | 输出 |
|---|---|---|
| `deepseek-flash`（推荐新手用） | 1 元（空闲时段）~ 2 元（高峰时段） | 4 元 ~ 8 元 |
| `deepseek-v4-pro` | 4.5 元 ~ 9 元 | 13.5 元 ~ 27 元 |

- 高峰时段：北京时间工作日 9:00–12:00、14:00–18:00；其余时间是空闲时段，**价格减半**
- 如果你发的内容和之前发过的开头一样，会命中“缓存”，输入价格更便宜（不用记，系统自动算）
- 价格会调整，以[官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)为准

**100 万 Token 有多少？** 大概相当于 150 万个中文字，好几本长篇小说。所以学完这个教程，一般只花几块钱。

> [!TIP]
> Agent 比聊天花钱多：因为它要“反复做”，每一圈都要把之前的内容再发一遍。第 23 章会教你怎么省钱。

### 上下文窗口：AI 一次能“记住”多少

AI 本身**没有记忆**。你和它聊天时，其实每次都要把**整段聊天记录**重新发给它一遍，它才知道之前聊了什么。

但它一次能读的长度有上限，这个上限叫**上下文窗口**(context window)。DeepSeek 现在的模型上限是 100 万 Token，非常大。

聊得太长超过上限，或者太长导致太贵，就需要“压缩”——把前面的内容总结成一小段。第 10 章会讲 DSH 怎么帮你自动做这件事。

### “OpenAI 兼容”：大家都用同一种菜单格式

OpenAI（做 ChatGPT 的公司）最早定了一种 API 的“菜单格式”。后来很多 AI 公司为了方便大家迁移，都用了**同一种格式**。这就叫 **“OpenAI 兼容”**。

好处是：**换一家 AI，只需要换“窗口地址”和“钥匙”，其他都不用改。**

DeepSeek 就是 OpenAI 兼容的。它还额外支持 Anthropic（做 Claude 的公司）的格式，地址是 `https://api.deepseek.com/anthropic`。

你会在后面的设置里看到这几种格式的选项：

| 格式名称 | 谁定的 |
|---|---|
| OpenAI Chat Completions | OpenAI（最常见） |
| OpenAI Responses | OpenAI（较新） |
| Anthropic Messages | Anthropic |
| Gemini API | Google |

**新手只要记住：用 DeepSeek 时，都不用改，默认就行。**

## 5. 常见问题

**问：网页版 DeepSeek 是免费的，为什么 API 要收费？**
答：网页版是给人聊天用的，有使用限制；API 是给程序用的，可以被 Agent 一圈一圈大量调用，所以按用量收费。网页版和 API 是**两个独立的账户体系**，网页版没有余额不影响 API，反过来也一样。

**问：钥匙会过期吗？**
答：DeepSeek 的钥匙不会自动过期，但你可以随时手动删除。建议不用的钥匙及时删掉。

**问：为什么同一个问题，有时候花的钱不一样？**
答：因为 AI 每次写的字数不一样，而且是否命中“缓存”、在不在高峰时段，都会影响价格。
