# 第 5 章 申请 DeepSeek API 钥匙

> **学完这一章，你能：**
> - 注册 DeepSeek 开放平台，充值，查看余额和用量
> - 创建一把 API 钥匙，并安全地保存它
> - 知道钥匙泄露了该怎么办
>
> **前置：** 第 3 章（知道 API 钥匙是什么、为什么它就是钱包）

## 1. 为什么要学这个

DSH 要用 DeepSeek 的 AI，就得有一把 **API 钥匙**。这一章带你一步步拿到它。

> [!TIP]
> DSH 桌面版也支持直接**登录 DeepSeek 账号**来使用（第 9 章会讲）。但学会自己管理 API 钥匙很重要：接其他 AI、用其他工具、写程序时都要用到。

## 2. 讲解

DeepSeek 有两个网站，**不要搞混**：

| 网站 | 地址 | 用途 |
|---|---|---|
| 聊天网页版 | chat.deepseek.com | 你平时聊天用的 |
| **开放平台** | **platform.deepseek.com** | 管理 API：充值、钥匙、用量 ← **这一章用这个** |

两边是**分开计费**的：网页版免费聊天，不影响 API 余额；API 余额也不能给网页版用。

## 3. 跟着做

### 第一步：注册并登录开放平台

1. 用浏览器打开 https://platform.deepseek.com
2. 用手机号（或页面支持的其他方式）注册并登录

**应该看到：** 开放平台的首页，左边有一列菜单，能看到“余额”"API keys"“用量信息”之类的入口。

<!-- 截图待补:开放平台首页。补图方法见 docs/screenshots.md -->

### 第二步：充值

1. 在左边菜单找到“充值”
2. 选择金额。**第一次学习，充 10 元就足够了**
3. 按页面提示用支付宝、微信等方式付款

**应该看到：** 回到首页，“余额”那里显示你充的金额。

> [!TIP]
> 有时新用户会有“赠送余额”，系统会**先扣赠送的**，再扣你充的。

> [!WARNING]
> 只在 **platform.deepseek.com** 这个官方网站充值。任何“代充”“低价额度”“共享钥匙”都可能是骗局，或者会泄露你的信息。

### 第三步：创建 API 钥匙

1. 左边菜单点"API keys"(或者直接打开 https://platform.deepseek.com/api_keys)
2. 点“创建 API key”
3. 给钥匙起个名字，写清楚是干什么用的，比如 `DSH-我的笔记本`
4. 点创建

**应该看到：** 弹出一个框，里面有一长串以 `sk-` 开头的字符。

> [!WARNING]
> **这串字符只显示这一次！** 关掉弹窗后就再也看不到了。请马上进行下一步，把它保存好。

### 第四步：安全地保存钥匙

**推荐做法：存进密码管理器。**

如果你用了密码管理器（比如 1Password、Bitwarden，或者 Mac 自带的“密码”App、浏览器自带的密码管理），新建一条记录：

- 名称：`DeepSeek API key - DSH`
- 内容：粘贴刚才那串 `sk-` 开头的钥匙
- 备注：创建日期、用在哪里

**不推荐但可以接受**：存在电脑里一个只有你知道的文本文件里，**不要放在桌面**，也不要放在会同步到网上或分享给别人的文件夹里。

> [!WARNING]
> **绝对不要做的事：**
> - 发到微信（包括“文件传输助手”）、QQ、邮箱
> - 截图
> - 写进 Word、笔记软件里再分享
> - 放进要上传到 GitHub 的文件夹
> - 发给任何“客服”或“技术支持”

> [!TIP]
> **一个用途一把钥匙。** 比如 DSH 用一把，自己写程序用另一把。哪把泄露了，只删那一把，不影响别的。名字写清楚用途，以后好管理。

### 第五步：看用量，心里有数

左边菜单的“用量信息”里，可以看到每天花了多少钱、用了多少 Token。

**建议：学习的头几天，每天看一眼。** 这样你会对“做一件事大概花多少钱”有感觉。

## 4. 钥匙泄露了怎么办

如果你怀疑钥匙泄露了（比如不小心截图发出去了、上传到网上了、余额突然少了很多）：

1. **马上**打开 https://platform.deepseek.com/api_keys
2. 找到那把钥匙，点“删除”。删除后，这把钥匙立刻失效，别人就再也用不了了
3. 新建一把钥匙，换到你用的地方（比如 DSH 设置里）
4. 去“用量信息”看看有没有不是你产生的费用

> [!TIP]
> 删掉钥匙**不会**删掉你的余额。余额还在账户里，只是那把钥匙不能再用了。

## 5. 自己检查

- [ ] 我分得清 chat.deepseek.com 和 platform.deepseek.com
- [ ] 我的开放平台账户有余额
- [ ] 我创建了一把钥匙，名字写清楚了用途
- [ ] 钥匙已经保存在安全的地方，而且没有发给任何人
- [ ] 我知道钥匙泄露了要马上删除、新建

## 6. 常见问题

**问：我关掉弹窗了，没来得及复制钥匙，怎么办？**
答：没关系。把那把钥匙删掉，重新创建一把就行。

**问：充多少合适？**
答：学这个教程，10 元足够。以后日常用，先充少量，看一两周的用量再决定。不要一次充很多。

**问：钥匙会不会自己扣很多钱？**
答：钥匙本身不会主动花钱，只有被调用时才扣费。只要你保管好、不泄露，就只有你自己的使用会扣钱。

**问：能退款吗？**
答：以 DeepSeek 平台的规则为准。所以建议少量多次充值。
