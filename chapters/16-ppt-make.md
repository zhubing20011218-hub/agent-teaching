# 第 16 章 实战一：让 AI 帮你做 PPT（从零到成功）

> **学完这一章，你能：**
> - 装好做 PPT 用的 `pptx` skill 和它需要的软件
> - 用一段话让 DSH 做出一份真正的 `.pptx` 文件
> - 检查成品，并让 AI 按你的意见修改
>
> **前置：** 第 15 章（会装 skill、会确认 skill 被调用）

## 1. 为什么要学这个

没有 skill 时，让 AI 做 PPT，它往往只能给你一份**文字大纲**，你还得自己一页页复制到 PowerPoint 里。

装上 `pptx` skill 后，AI 就知道：

- 怎么**生成真正的 `.pptx` 文件**（能直接用 PowerPoint、WPS、Keynote 打开）
- 怎么**读取**你已有的 PPT
- 做完后怎么**把每一页转成图片，自己检查**有没有文字跑出框、排版重叠
- 有哪些**常见的坑**（比如某些字体在别人电脑上显示不出来）

这些都是它自己“不知道”、但写在说明书里的经验。

## 2. 讲解：`pptx` skill 需要哪些“帮手软件”

`pptx` skill 是 Anthropic 官方写的，用 **Apache 2.0** 开源许可（免费使用、可以转发）。

它的说明书里会让 AI 用到几个软件。打个比方：skill 是“菜谱”，这些软件是“厨具”。菜谱写得再好，没有锅也做不了菜。

| 软件 | 用来干什么 | 一定要装吗 |
|---|---|---|
| **Node.js** + `pptxgenjs` | **生成** PPT 文件 | ✅ 必须 |
| **Python** + 几个小工具包 | **读取** PPT 内容、生成缩略图、检查文件有没有错 | ✅ 必须 |
| **LibreOffice** | 把 PPT **转成 PDF / 图片**，让 AI 自己检查排版 | 强烈建议 |
| **Poppler**(`pdftoppm`) | 把 PDF 转成一张张图片 | 强烈建议 |

> [!TIP]
> 没装 LibreOffice 和 Poppler,AI 也能做出 PPT，只是**没法自己“看”做出来的样子**，排版问题要靠你自己检查。

## 3. 跟着做

### 第一步：安装 `pptx` skill

按第 15 章的方法一，在 DSH 里输入：

```
请帮我安装一个 skill:
把 https://github.com/anthropics/skills 仓库里 skills/pptx 这个文件夹
(包括里面的 scripts 文件夹和 LICENSE.txt)复制到 ~/.dsh/skills/pptx。
如果 ~/.dsh/skills/pptx 已经存在,先告诉我,不要直接覆盖。
装好后列出 ~/.dsh/skills/pptx/ 里的文件和文件夹给我确认。
```

审批时看清是复制到 `~/.dsh/skills/pptx`，点「允许一次」。

**应该看到：** `~/.dsh/skills/pptx/` 里有 `SKILL.md`、`LICENSE.txt`、`scripts/`。

> [!TIP]
> 手动安装也可以：打开 https://github.com/anthropics/skills →「Code」→「Download ZIP」→ 解压后进入 `skills` 文件夹，把 **`pptx` 整个文件夹**复制进 `~/.dsh/skills/`。

> [!TIP]
> 以前装过旧版的 `pptx` skill?旧版的许可证比较严格，而且内容较旧，建议删掉旧的、装最新版。

装好后，按第 15 章的方法，输入 `/pptx` 确认它出现在指令菜单里。

### 第二步：安装 LibreOffice（手动，只要一次）

1. 打开 https://www.libreoffice.org/download/download-libreoffice/
2. 下载适合你电脑的版本（Mac 选 Apple 芯片 / Intel;Windows 选 x86_64）
3. 像普通软件一样安装

**应该看到：** 应用程序里多了 LibreOffice。打开一次，确认能运行，然后关掉。

### 第三步：让 DSH 检查并安装其他软件

在 `ai-练习` 里新建一个文件夹 `PPT练习`，把它设为工作区。权限选「**工作区内修改**」，输入：

```
我要用 pptx skill 做 PPT。请先阅读 pptx skill 的说明,
然后检查我电脑上它需要的软件是否都装好了:
Node.js 和 pptxgenjs、Python 和它需要的 Python 包、LibreOffice、Poppler(pdftoppm)。
列一张表告诉我:哪些有、哪些没有。
没有的:能用 pip 或 npm 安装的,告诉我你要执行的命令,等我同意后再安装;
需要我手动安装的,告诉我怎么装。
```

**应该看到：** 一张检查表。它要安装东西时会弹审批，看清命令(一般是 `pip install …` 或 `npm install …`)，确认后「允许一次」。

> [!TIP]
> **Poppler 在 Mac 上**一般用 Homebrew（Mac 上的“软件管家”）安装：`brew install poppler`。如果你没有 Homebrew,AI 会告诉你怎么装。**Windows 上**比较麻烦，可以先跳过，AI 会退而用其他办法检查。

### 第四步：第一次做 PPT

**一段好的“做 PPT”指令，要说清 5 件事：**

| 要说清 | 为什么 |
|---|---|
| **主题** | 讲什么 |
| **给谁看** | 老板、客户、同学、家长……决定用词和深浅 |
| **讲多久 / 几页** | 决定内容量 |
| **风格** | 简洁商务、活泼、学术…… |
| **交付要求** | 文件名、放哪里、要不要演讲备注 |

试试这段（可以换成你自己的主题）：

```
请用 pptx skill 帮我做一份 PPT。
- 主题:新手怎么用 AI 提高工作效率
- 给谁看:公司里不懂技术的同事
- 时长:10 分钟,大约 8 页
- 风格:简洁、白底、颜色不超过 3 种,字要大
- 每页加 1–2 句演讲备注
- 文件保存为 PPT练习/AI提效分享.pptx
先给我看每一页的标题和要点,我确认后再生成文件。
做完后请把每一页转成图片自己检查一遍,有文字溢出、重叠的地方先修好再交给我。
```

**接下来会发生什么：**

1. 对话里出现「**加载技能**」→ 点「查看」确认是 `pptx`
2. AI 给你一份 8 页的大纲 → 你检查、提修改意见，或者回复“可以，开始做”
3. AI 写一个小程序来生成 PPT（这是 skill 教它的做法，你不用看懂）
4. AI 运行检查工具，把 PPT 转成图片，自己“看”一遍，修掉问题
5. AI 告诉你：做好了，文件在哪里

整个过程可能要几分钟，中途可能会弹出几次审批（运行它写的程序）。

### 第五步：打开检查

用 PowerPoint、WPS 或 Keynote 打开 `PPT练习/AI提效分享.pptx`。

检查清单：

- [ ] 页数、标题对不对
- [ ] 有没有文字跑出框外、被截断
- [ ] 有没有元素重叠
- [ ] 字体显示正常吗（有没有变成奇怪的字体）
- [ ] 演讲备注有没有（PowerPoint 里在每页下方的“备注”区）
- [ ] 内容有没有**事实错误**（AI 可能编造数字，要自己核对）

### 第六步：让它改

**提修改意见要具体**，说清“哪一页、什么问题、改成什么样”:

- ❌ “不太好看，改改”
- ✅ “第 3 页字太多，拆成两页；第 5 页的图表颜色太花，改成同一种蓝色的深浅；封面标题再大一点”

```
修改 PPT练习/AI提效分享.pptx:
1. 第 3 页字太多,拆成两页
2. 第 5 页图表改成同一种蓝色的深浅
3. 封面标题字号再大一点
改完重新转成图片检查一遍,然后另存为 AI提效分享_v2.pptx,保留原来的文件。
```

> [!TIP]
> **“另存为新文件，保留原来的”** 是好习惯。万一改坏了，还能回到上一版。

## 4. 自己检查

- [ ] `~/.dsh/skills/pptx/` 装好了，`/pptx` 能在指令菜单里找到
- [ ] LibreOffice 装好了
- [ ] DSH 帮我检查过依赖软件，缺的都装上了
- [ ] 我做出了一份能打开的 `.pptx`
- [ ] 我看到了「加载技能」那一行

## 5. 常见问题

**问：AI 只给了我文字大纲，没生成文件？**
答：检查有没有「加载技能」那一行。没有的话，在指令开头加 `/pptx`，并明确说“生成 .pptx 文件”。

**问：报错找不到 `pptxgenjs`?**
答：让 AI 在工作区里安装：“请在当前文件夹运行 npm install pptxgenjs”。

**问：报错找不到 `soffice` 或 LibreOffice?**
答：LibreOffice 没装，或者 AI 找不到它。确认已安装后，告诉 AI:“LibreOffice 已经装在 应用程序 / Program Files 里了，请找到它的位置再试。”

**问：中文变成方框或乱码？**
答：字体问题。告诉 AI:“中文用微软雅黑（Windows）或苹方（Mac）这类系统自带字体”，或者说清你要用的字体。如果 PPT 要发给别人，尽量用对方电脑上也有的常见字体。

**问：做一份 PPT 花多少钱？**
答：用 `deepseek-flash`，一份 10 页左右的 PPT，包括检查和修改，一般在几毛钱以内。去 DeepSeek 开放平台的“用量信息”里可以看到实际花费。

**问：AI 编了一些不存在的数据？**
答：大模型会“幻觉”（第 2 章）。数据类内容，请**把真实数据给它**（“用下面这些数字做图表：……”），不要让它自己想。第 18 章专门讲怎么让它查到靠谱资料。
