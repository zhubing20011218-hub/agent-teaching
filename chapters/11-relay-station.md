# 第 11 章 中转站：学校网关和公开中转站

> **学完这一章，你能：**
> - 说清楚中转站是什么、帮你做了什么
> - 分清两种中转站：只能在单位里用的**内部网关**，和谁都能注册的**公开中转站**
> - 在中转站后台拿到令牌、找到地址，接进 DSH
> - 判断一个中转站靠不靠谱，知道哪些资料**不能**发过去
>
> **前置：** 第 10 章（会用自定义渠道）

## 1. 为什么要学这个

很多人第一次用 AI 接口，不是直接找 AI 公司，而是通过**中转站**：

- 学校、公司统一买好额度，发给你一个“内部 AI 地址”
- 网上的中转站，一个账号就能用好几家的 AI

它很方便，但你的内容会**经过别人的服务器**。所以除了“怎么接”，还要学会“怎么挑”和“什么不能发”。

## 2. 讲解

### 中转站 = 代购

你想买国外的东西，可以自己去官网买，也可以找代购。

中转站就是 AI 的“代购”：

1. 你把请求发给中转站
2. 中转站用**它自己的**钥匙，把请求转给真正的 AI 公司
3. AI 公司把回复给中转站，中转站再转给你
4. 中转站按你的用量，从**你在它那里的余额**里扣钱

所以：
- 你的钥匙是**中转站发的**，不是 AI 公司发的
- 你的地址填的是**中转站的地址**
- 你发的每一句话、AI 读的每一个文件，**中转站都经手**

### 两种中转站

| | 🏫 单位内部网关 | 🌐 公开中转站 |
|---|---|---|
| 谁搭的 | 学校、公司的技术部门 | 个人或公司，在网上经营 |
| 在哪里能用 | **只能在单位网络里**（校园网、公司内网，或者连上单位 VPN） | 任何地方都能用 |
| 怎么登录 | 通常用学号、工号（统一身份认证） | 自己注册账号 |
| 谁付钱 | 单位，按人分配额度 | 你自己充值 |
| 地址长什么样 | 常常是内网地址，比如 `http://10.20.30.40:3000/v1` | 普通网址，比如 `https://api.example.com/v1` |
| 数据去哪里 | 先到单位的服务器 | 先到经营者的服务器 |

**为什么内部网关一出门就用不了？** 内网地址就像“宿舍楼里的房间号”。在楼里一说就找到了；出了校门，外面的人不知道“302 室”在哪里。

> [!TIP]
> 两种中转站背后用的软件常常是**同一类**，比如开源的 New API、One API、LiteLLM。所以它们的后台长得很像，学会一个，另一个也会用。

### 后台里的几个词

| 后台里的词 | 意思 |
|---|---|
| **令牌** | 就是 API 钥匙，多数以 `sk-` 开头。⚠️ 和第 3 章讲的计费单位 Token 不是一回事，只是英文碰巧都叫 token |
| **额度** / 余额 | 你还能用多少钱 |
| **倍率** | 价格系数，第 5 节讲怎么算 |
| **分组** | 不同的价格档或线路，一般用默认的就行 |
| **模型广场** / 价格 | 列出能用哪些模型、各多少钱 |
| **使用日志** | 每一次调用用了哪个模型、扣了多少钱 |
| **渠道** | 管理员配置上游 AI 的地方。普通用户看不到，也不用管 |

## 3. 跟着做 A：学校的内部网关

> [!WARNING]
> 每个学校的系统不一样。下面是通用步骤，具体以你们学校的说明为准。

### 第一步：连上学校网络

- 在学校：连校园网（Wi-Fi 或网线）
- 在校外：先打开学校的 VPN 并登录

**怎么确认连上了：** 用浏览器打开学校给的 AI 服务网址，能看到登录页面。

<!-- 截图待补：学校 AI 服务的登录页（学校名称、个人信息打码）。补图方法见 docs/screenshots.md -->

### 第二步：登录，创建令牌

1. 用学号或工号登录
2. 找到「**令牌**」（也可能叫「API 密钥」「API Keys」）页面
3. 点「**添加令牌**」或「新建」，名字填 `dsh`
4. 创建后，点「**复制**」，把钥匙存进你的密码记事本

<!-- 截图待补：学校网关的令牌页面（令牌打码）。补图方法见 docs/screenshots.md -->

### 第三步：找到地址和模型名

- **地址**：看学校的接入说明。如果给的是完整地址，按第 10 章第 4 节的方法抠出基础地址
- **模型名**：看说明里的模型列表，或者后台的「模型广场」

### 第四步：接进 DSH

按第 10 章第 4 节填写自定义渠道：

| 框 | 填什么 |
|---|---|
| Provider ID | `school-ai` |
| 显示名称 | 学校 AI |
| API 协议 | 按说明，一般是 OpenAI Chat Completions |
| API 地址 | 学校的基础地址，比如 `http://10.20.30.40:3000/v1` |
| API 密钥 | 刚才复制的令牌 |

然后「获取可用模型」→ 勾选 →「创建提供商」→ 发一句话测试。

<!-- 截图待补：DSH 里填好的学校网关自定义渠道（地址、令牌打码）。补图方法见 docs/screenshots.md -->

### 学校网关的规矩

- **离开学校网络就连不上**：DSH 会一直转圈或报网络错误。这是正常的，连上 VPN 再用
- **学校看得到使用记录**：用于学习和工作，别拿去做和学校无关的事
- **令牌只给自己用**：借给别人，额度和记录都算在你头上

### 第一步：注册并登录

1. 打开网站，点「注册」
2. 按提示填写，登录

### 第二步：少量充值

1. 进入「**钱包**」或「充值」页面
2. **第一次只充一点点**（比如 10 元），确认好用再说

### 第三步：创建令牌

1. 进入「**令牌**」页面，点「**添加令牌**」
2. 填写：
   - **名称**：`dsh`
   - **额度**：建议设一个上限（比如 10 元），而不是“无限额度”。万一令牌泄露，最多损失这么多
   - **过期时间**：可以设一个日期，到期自动失效
   - 其他选项先用默认的
3. 提交后，在令牌列表里点「**复制**」

| DSH 里选的协议 | API 地址 |

### 第五步：接进 DSH，测试

1. 按第 10 章第 4 节，新建自定义渠道：Provider ID 填 `relay1`，协议选 OpenAI Chat Completions，地址填 `https://api.prismice.cn/v1`，粘贴令牌
2. 「获取可用模型」→ 勾选 →「创建提供商」
3. 新建会话，选这个模型，发一句话

**应该看到：** 有回复。

1. 回到中转站后台，打开「**使用日志**」
2. 找到刚才那一次调用，看两样：**模型名**对不对，**扣了多少钱**

## 5. 怎么挑一个靠谱的中转站

### 看价格：倍率怎么算

很多中转站不直接写价格，而是写“倍率”。大致的意思是：

> **实际价格 ≈ 基础价格 × 倍率**

倍率 `1` 就是按基础价，`0.5` 是半价，`2` 是两倍。有的网站还叠加“分组倍率”，几个倍率要乘在一起算。

**不要只靠心算。** 最可靠的办法就是第 4 节第六步：用一次，看日志里实际扣了多少。

### 看是不是“真模型”

有的中转站会拿便宜的模型冒充贵的模型。下面的办法**都不是百分之百准**，但可以帮你发现明显的问题：

1. **问 AI“你是谁”不算数**：它答错自己是谁很常见
2. **同一个问题，官方问一次，中转站问一次**：选一个需要认真推理的问题，对比两边答案的水平
3. **看使用日志**：日志里记录的模型名和价格，要和你选的一致
4. **看速度和长度**：贵模型通常能读更长的文件。中转站读长文件总是失败，就要小心

### 安全清单

- [ ] 第一次只充少量钱，不要一次充几百几千
- [ ] 令牌设额度上限和过期时间
- [ ] 不把敏感资料发过去（见下面的表）
- [ ] 网站突然大幅降价、催你多充值的，要警惕
- [ ] 遵守 AI 公司的服务条款和当地法律。有的模型在某些地区不对外提供，转卖可能违反规定

### 什么资料不能走公开中转站

你发给 AI 的内容，包括 AI 读过的文件，中转站**技术上都能看到、能保存**。

| 🚫 不要发 | ✅ 可以发 |
|---|---|
| 身份证号、银行卡号、账号密码 | 公开的资料、新闻、教材内容 |
| 客户的财务数据、合同 | 去掉姓名和金额的示例数据 |
| 学生名单、成绩、家长电话 | 不含个人信息的教学设计 |
| 公司没公开的方案、代码、数据 | 你自己愿意公开的稿子 |
| 别人的聊天记录、照片 | 自己拍的风景照 |

**敏感资料要么不让 AI 碰，要么只走你信得过的渠道。** 信得过的渠道是指官方接口，或者单位自己的内部网关。

## 7. 练习

### 🧾 阿芳（会计）：哪些能发？

下面三份资料，哪些可以通过公开中转站让 AI 处理？

1. 公司公开发布的年度报告 PDF
2. 一份客户银行流水，带姓名和账号
3. 你自己编的 20 行假流水，用来练习对账

<details>
<summary>参考答案</summary>

- 1 可以：已经公开的资料
- 2 **不可以**：有客户姓名和账号，属于敏感财务数据。要么只走官方或单位网关，要么先把姓名和账号全部去掉
- 3 可以：假数据，没有真实信息

</details>

### ✈️ 阿远（旅行）：算一算

某中转站写着：某模型基础价每百万 Token 2 元，倍率 `0.8`，你的分组倍率 `1.5`。大约每百万 Token 多少钱？比官方的 2 元贵还是便宜？

<details>
<summary>参考答案</summary>

2 × 0.8 × 1.5 = **2.4 元**，比官方的 2 元还贵。看起来打了八折，叠加分组倍率之后反而更贵了。所以一定要用一次，看日志里实际扣了多少。

</details>

## 9. 常见问题

**问：在学校能用，回家就一直转圈？**
答：内部网关只能在单位网络里用。回家要先连学校 VPN。

**问：余额扣得比想的快？**
答：AI 读文件、多轮对话都算用量，文件越大扣得越多。去「使用日志」看是哪几次扣得多；做大任务前先用小文件试。

**问：报错 `无可用渠道`、`model not found`？**
答：这个中转站没有你填的模型，或者你的分组不能用它。去「模型广场」核对模型名，或者换一个模型。

**问：换了一个中转站，要重新建吗？**
答：要。新建一个自定义渠道（Provider ID 换一个名字），旧的不用了就删掉。

**问：中转站的令牌泄露了怎么办？**
答：马上去后台「令牌」页面删除或禁用它，再新建一个，然后在 DSH 里点「编辑」换成新令牌。因为你设了额度上限，损失最多就是那个上限。
