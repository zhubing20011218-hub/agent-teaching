# 第 6 章 安装 DSH

> **学完这一章，你能：**
> - 根据你的电脑，选对安装方式
> - 装好并打开 DeepSeek Harness(DSH)
> - 知道 DSH 把你的数据存在电脑哪里、怎么升级
>
> **前置：** 第 4 章（知道 DSH 是什么）、第 5 章（有一把 API 钥匙）

## 1. 为什么要学这个

前面讲了那么多概念，这一章终于要**装上一个真正的 Agent**了。

## 2. 选对安装方式

DSH 有两种用法，界面和功能基本一样：

| | 🖥️ 桌面版（推荐新手） | 🌐 网页版 |
|---|---|---|
| 是什么 | 像微信一样的独立软件 | 在浏览器里打开的界面 |
| 怎么装 | 下载安装包，双击安装 | 先装 Node.js，再在终端里输一条命令 |
| 要用终端吗 | **不用** | 要用一次 |
| 适合 | Apple 芯片的 Mac(M1/M2/M3/M4…)、Windows 64 位 | 所有电脑，包括 Intel 芯片的 Mac、Linux |

**先查一下你的电脑：**

- **Mac**：点左上角苹果图标 → “关于本机”，看“芯片”那一行。写着 `Apple M…` 的，用**桌面版**；写着 `Intel` 的，用**网页版**
- **Windows**:Windows 10 / 11 的 64 位系统（现在的电脑几乎都是），用**桌面版**

## 3. 跟着做：安装桌面版（推荐）

### 第一步：下载

1. 打开官网：https://deepseek.com/harness
2. 点“下载桌面端”，选择你的系统：
   - Mac（Apple 芯片）：下载 `.dmg` 文件
   - Windows：下载 `.exe` 文件

> [!WARNING]
> **只从官网 deepseek.com 下载。** 不要从网盘、群文件、第三方下载站下载“DeepSeek Harness 安装包”，可能被人改过、带病毒。

### 第二步：安装

**Mac:**

1. 双击下载好的 `.dmg` 文件
2. 在弹出的窗口里，把 DeepSeek Harness 图标**拖到**旁边的“应用程序”文件夹
3. 打开“启动台”或“应用程序”文件夹，双击 DeepSeek Harness

**Windows:**

1. 双击下载好的 `.exe` 文件
2. 按安装向导点“下一步”，直到完成
3. 从开始菜单或桌面图标打开 DeepSeek Harness

**应该看到：** 一个欢迎页面，写着「**欢迎使用 DeepSeek Harness**」，下面有两个按钮：「**登录**」和「**添加 API Key**」。

## 4. 跟着做：安装网页版（Intel Mac、Linux，或者你想用浏览器）

### 第一步：安装 Node.js

**Node.js** 是一个让很多程序能运行的“底座软件”。DSH 网页版需要它。

1. 打开 https://nodejs.org
2. 下载标着 **LTS**（长期支持版，最稳定）的版本
3. 双击安装，一路点“下一步”（Mac 上可能要输入开机密码）
4. 打开终端（第 1 章教过），输入下面的命令检查：

```bash
node --version
```

**应该看到：** `v22.` 或 `v24.` 开头的版本号（数字越大越新）。

### 第二步：启动 DSH 网页版

在终端里输入：

```bash
npx @deepseek-ai/dsh web
```

第一次运行要下载，等一两分钟。中间如果问你 `Ok to proceed? (y)`，输入 `y` 按回车。

**应该看到：** 浏览器自动打开一个页面，地址是 `http://127.0.0.1:3080` 开头的。这就是 DSH 网页版。

> [!TIP]
> `127.0.0.1` 的意思是“**你自己这台电脑**”。这个网页是你电脑上的 DSH 提供的，别人访问不到。

> [!WARNING]
> **终端窗口不要关**，关了 DSH 就停了。不用的时候，在终端里按 `Ctrl + C` 停止。下次用，重新输一遍上面的命令。

## 5. DSH 把东西存在哪里

DSH 的设置、聊天记录、skill 等，都存在你用户文件夹里一个叫 `.dsh` 的**隐藏文件夹**里（第 1 章教过怎么看隐藏文件夹）：

- Mac:`/Users/你的名字/.dsh`
- Windows:`C:\Users\你的名字\.dsh`

里面几个重要的东西：

| 名字 | 是什么 | 能不能发给别人 |
|---|---|---|
| `.credentials.yaml` | **你保存的钥匙** | ⚠️ **绝对不能** |
| `sessions/` | 你和 AI 的聊天记录 | 不建议，里面可能有你的文件内容 |
| `skills/` | 你装的 skill（第四部分会用） | 可以 |
| `profiles/` | 各种配置 | 发之前要检查有没有钥匙 |

> [!WARNING]
> 有人让你"把 `.dsh` 文件夹打包发过来帮你看看问题"?**不要发。** 里面有你的钥匙和聊天记录。

## 6. 怎么升级

DSH 更新很快（经常一周几个新版本）。

- **桌面版**：应用菜单里有「**检查更新…**」（Mac 在屏幕左上角的"DeepSeek Harness"菜单里）。有新版本会提示你安装
- **网页版**：每次用 `npx @deepseek-ai/dsh web` 启动，一般会自动用最新版。如果没更新，可以用 `npx @deepseek-ai/dsh@latest web`

> [!TIP]
> **升级前先结束正在进行的任务。** 升级时如果有任务在跑，会被中断。

## 7. 关闭和退出（桌面版）

- **点窗口的关闭按钮**：窗口只是**隐藏**了，DSH 还在后台运行，正在做的任务不会中断
  - Mac：点 Dock 栏上的图标找回窗口
  - Windows：在右下角的托盘图标里找回
- **真正退出**：Mac 按 `⌘ + Q`;Windows 右键托盘图标 →「退出 DeepSeek Harness」。如果有任务还在跑，会先问你

## 9. 常见问题

**问：Mac 提示“无法打开，因为无法验证开发者”?**
答：先确认安装包是从 deepseek.com 官网下载的。然后打开“系统设置” → “隐私与安全性”，在下面找到关于 DeepSeek Harness 的提示，点“仍要打开”。**只对官网下载的软件这样做。**

**问：网页版报错 `command not found: npx` 或 `'npx' 不是内部或外部命令`?**
答：Node.js 没装好，或者装完没有重新打开终端。关掉终端，重新打开再试；还不行就重新安装 Node.js。

**问：网页版报错端口被占用(`EADDRINUSE`、`3080`)?**
答：可能 DSH 已经在运行了（比如另一个终端窗口里）。找到那个窗口用 `Ctrl + C` 停掉，或者直接用已经开着的那个。

**问：Windows 上提示“禁止运行脚本”?**
答：用管理员身份打开 PowerShell，输入 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，按回车，输入 `Y` 确认。这只对你自己的账户生效，允许运行本地和已签名的脚本。

**问：桌面版和网页版能同时装吗？**
答：可以，它们共用同一个 `~/.dsh` 文件夹。但新手用一个就够了，不要同时开两个，避免互相影响。
