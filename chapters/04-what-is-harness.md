# 第 4 章 Harness 是什么(为什么有了 API 还不够)

> **学完这一章,你能:**
> - 说清楚"只有 API"和"有了 Harness"的区别
> - 说出 Harness 帮你做的 5 件事
> - 知道 DeepSeek Harness(DSH)和 Claude Code、Codex 是同一类东西
>
> **前置:** 第 2、3 章

## 1. 为什么要学这个

上一章讲了 API:你把话递进去,AI 把回答递出来。

但还记得第 2 章说的吗?**大模型只会输出文字,它没有手。** 就算通过 API,AI 回给你的也只是一段文字,比如:

> "请运行命令 `mv IMG_001.jpg 2026-05-01.jpg` 来改名。"

**谁来真的执行这条命令?** 谁来把结果告诉 AI?谁来防止 AI 执行危险的命令?

这就是 **Harness** 要做的事。

## 2. 讲解

### Harness:给 AI 配的"马具"

Harness 这个英文词,本来的意思是**马具**——套在马身上的缰绳、马鞍。

马(大模型)力气很大,但没有马具,人既用不上它的力气,也控制不住它。**Harness 就是让人能"驾驭"大模型的那套装备。**

所以本教程把 Harness 叫做**驾驭程序**。它是一个装在**你电脑上**的程序。

### 只有 API vs. 有了 Harness

| | 只有 API | 有了 Harness |
|---|---|---|
| AI 说"请运行这条命令" | 你自己复制去运行 | Harness **帮它运行**(危险的先问你) |
| 运行的结果 | 你自己复制回去告诉 AI | Harness **自动把结果交回给 AI** |
| 一个任务要 10 步 | 你来回复制粘贴 10 次 | Harness **自动一圈一圈做完** |
| 聊天记录 | 你自己保存 | Harness **自动保存**,下次接着聊 |
| AI 想删你的文件 | —— | Harness **拦下来先问你** |

### Harness 帮你做的 5 件事

1. **提供工具(双手)**:读文件、写文件、运行命令、上网搜索……这些"动作"都是 Harness 提供的
2. **跑循环(反复做)**:AI 要用工具 → Harness 去执行 → 把结果交回 AI → AI 想下一步……直到完成
3. **把关(权限审批)**:危险操作先问你;还能限定 AI 只能动某一个文件夹
4. **管记忆(上下文)**:保存聊天记录;聊太长时自动压缩
5. **能扩展**:你可以给它装新本事——**skill**(说明书)、**MCP**(外部工具)、**插件**(新功能)。这是第四、五部分的内容

关键点:**大脑在 DeepSeek 的服务器上,双手在你的电脑上,Harness 是中间的指挥。**

### DeepSeek Harness 是什么

**DeepSeek Harness** 是 DeepSeek 公司开源的(代码公开、免费使用)一个 Harness,简称 **DSH**,命令名叫 `dsh`。

它的特点:

- 有**桌面版**(像普通软件一样安装,新手推荐)和**网页版**(在浏览器里用)
- 默认用 DeepSeek 的模型,也能接其他家的 AI
- 核心理念是"**一切皆插件**":所有功能都是可以装、可以拆的零件,方便定制
- 支持 skill、MCP、插件这些扩展方式

官方网站:https://deepseek.com/harness
代码仓库:https://github.com/deepseek-ai/deepseek-harness

### 同类产品:学会一个,其他都相通

| 名字 | 谁做的 | 默认用谁的 AI |
|---|---|---|
| **DeepSeek Harness** | DeepSeek | DeepSeek |
| Claude Code | Anthropic | Claude |
| Codex | OpenAI | GPT |
| OpenCode | 开源社区 | 多家都行 |

它们的原理一模一样:**大模型 + 工具 + 循环 + 审批 + 扩展**。本教程用 DSH 来讲,但你学到的概念(尤其是 skill)在其他工具里同样适用。

> 💡 本教程第四部分讲的 skill,格式和 Claude Code、Codex 基本通用。一份 skill 写好,几个工具都能用。

### "模型"、"API"、"Harness"三者的关系

最后用一句话把三个概念串起来:

> **模型**是大脑,**API** 是你和大脑之间的电话线,**Harness** 是帮大脑长出双手、并替你看着它的管家。

## 5. 常见问题

**问:Harness 会把我电脑上的文件都发给 DeepSeek 吗?**
答:不会全部发。只有 AI 在任务中**读取过的内容**,才会作为聊天记录的一部分发给 DeepSeek。所以:不要让它读你不想发给别人的文件(比如身份证照片、密码本);只给它需要的文件夹。

**问:DSH 是免费的吗?**
答:DSH 软件本身免费、开源。但它调用 DeepSeek 的 AI 需要付 API 的费用(第 3 章讲的 Token 收费)。

**问:一定要用 DSH 吗?**
答:不一定。如果你已经在用 Claude Code、Codex,概念都是相通的。本教程选 DSH,是因为它默认用 DeepSeek,在国内用起来方便、价格便宜。
