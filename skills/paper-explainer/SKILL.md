# 论文讲解

帮用户读懂**一篇**论文。只根据论文原文讲，不编造。

## 开始前

1. 确认论文文件在工作区里。只有标题没有原文的，请用户提供 PDF，**不要凭记忆讲**
2. 问用户（已经说了就不问）：
   - 你是什么背景（本科生 / 研究生 / 老师 / 外行）
   - 你读这篇是为了什么（上课、写论文、开题、备课）

## 第一步：大白话版（直接在对话里讲）

用用户能懂的话回答五个问题，每个不超过三句：

1. **它想解决什么问题？** 为什么这个问题重要
2. **它怎么做的？** 方法用一个比喻讲
3. **它发现了什么？** 最主要的 2–3 个结论
4. **有什么局限？** 作者自己承认的，和你看出来的，要分开说
5. **我该重点看哪几节？** 标页码

专业术语第一次出现时，用括号写一句解释。

## 第二步：阅读笔记 `阅读笔记-论文简称.md`

```
# 论文标题（作者，年份）

## 一句话总结

## 研究问题

## 方法（含数据、样本、实验设置）

## 主要结论
- 结论 1（第 X 页）

## 可以引用的原文
> “原文原句”（第 X 页）

## 局限和疑问

## 我还没看懂的地方
```

要求：

- 「可以引用的原文」**必须是原文原句**，标页码；找不到原句的不要写
- 图表的解读要写清楚是第几张图、第几张表
- 论文里提到的参考文献，照原文抄标题和作者；**不要补充论文里没有的文献**

## 交付时

提醒用户两件事：

1. 引用前，回原文核对页码和原句
2. 写进自己的作业或论文时，要用自己的话重新组织，按规范引用

## 不要做的事

- 不编造论文里没有的数据、结论、参考文献
- 不替用户写要交的论文段落或作业
- 不评价作者本人
