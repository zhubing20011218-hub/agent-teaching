# 复习资料包

把用户给的学习材料，变成三样东西：**复习手册**、**题库**、**离线自测网页**。所有内容只来自用户给的材料。

## 开始前

1. 确认材料在工作区里（PDF、PPT、Word、笔记都行），读不了的格式先告诉用户
2. 问用户三件事（用户已经说了就不问）：
   - 这是什么课、什么程度（本科几年级 / 考研 / 自学）
   - 要哪几样：复习手册、题库、自测网页，还是全部
   - 题目数量和题型（默认：选择 10、判断 5、简答 5）

## 第一步：复习手册 `复习手册.md`

每个知识点按这个格式写：

```
### 知识点名称（课件第 X 页）
- 一句话大白话：……
- 原文定义：……（照抄材料原文，不改写）
- 例子或例题：……（材料里有才写；例题写完整步骤）
- 容易错的地方：……（材料里提到才写）
```

要求：

- **每一条都标出处**（页码、幻灯片编号或小节号）
- 材料里没有的内容不要加。拿不准的，标「（不确定，请对照原文）」
- 公式照原样写，不要自己推导新公式

## 第二步：题库 `题库.md`

- 按用户要的题型和数量出题，难度从易到难
- 每题标出考的是哪个知识点、出处在第几页
- 答案和解析放在文件最后，单独一节
- 计算题的答案要按材料里的方法算一遍；用程序算的，把计算过程写出来

## 第三步：自测网页 `自测.html`

做成**一个**离线网页文件，双击就能打开：

- 不联网、不加载外部资源、不收集任何信息
- 一次显示一题；选择题点选项，简答题显示参考答案让用户自己对照
- 做完显示得分，列出错题和对应的知识点、出处
- 有“只练错题”按钮
- 进度只存在浏览器本地（localStorage），可以清空

## 交付时

用三句话告诉用户：做了哪几个文件、各有多少条、建议先怎么用。

最后提醒一句：**请对照原文抽查几条知识点和答案，AI 也可能出错。**

## 不要做的事

- 不编造材料里没有的知识点、数据、参考文献
- 不替用户完成要交的作业、论文、实验报告
- 不把材料内容发到工作区以外
