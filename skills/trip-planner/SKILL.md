# 行程规划

帮用户规划一次旅行。**先问清楚，再动手；时间、价格这类会变的信息，一律标为“待核对”。**

## 第一步：先问清楚（一次问完，最多 8 个问题）

用户已经说了的就不问：

1. 目的地、出发地、日期、玩几天
2. 几个人，有没有老人、小孩、行动不便的人
3. 总预算大概多少，住宿想要什么档次
4. 喜欢什么：自然风光 / 历史人文 / 美食 / 购物 / 拍照
5. 每天能接受走多少路，喜欢早起还是睡懒觉
6. 交通方式：自驾 / 公共交通 / 打车
7. 有没有一定要去、一定不去的地方
8. 有没有饮食禁忌

## 第二步：排行程 `行程.md`

- 按天排，每天按上午、中午、下午、晚上写
- **同一天的地点要顺路**，写清楚地点之间怎么去、大概多久
- 每天留出吃饭、休息和排队的时间，不要排满
- 需要提前预约或买票的，标「⚠️ 需要提前预约」
- 开放时间、票价写成「待核对」，不要凭印象写具体数字

## 第三步：预算表 `预算.xlsx`（或 `预算.csv`）

列：类别（交通 / 住宿 / 门票 / 餐饮 / 其他）、项目、单价、数量、小计、备注。

- 查不到的价格写「待查」，**不要估一个数填进去**
- 合计用表格公式计算

## 第四步：核对清单 `出发前核对.md`

列出所有需要用户自己去官方渠道确认的事：

- 每个景点的开放时间、门票、预约方式（写上应该去哪里查：景区官网、官方公众号等）
- 交通班次
- 天气
- 证件、签证（出境游）

如果工作区里有可以联网搜索的工具，可以先查一遍，但**每条都要写来源和查询日期**，查不到就保留「待核对」。

## 交付时

用三句话说明：行程几天、预算大概多少、有几项需要出发前核对。

## 不要做的事

- 不编造开放时间、票价、班次
- 不要求用户提供护照号、身份证号、订单号
- 不替用户下单、付款、预约
