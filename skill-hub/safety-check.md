# 安装前的安全检查

> **这一页是一张随手可用的检查卡。** 详细讲解在教程第 15 章第 7 节。

skill 是写给 AI 看的说明书。你装了它，AI 就会**照着它做事**，包括运行里面的脚本。所以装别人的 skill，和装别人的软件一样，要先看一眼。

## 1. 三分钟检查卡

| # | 看什么 | 怎么看 | 🚩 危险信号 |
|---|---|---|---|
| 1 | **许可证** | 仓库首页右侧的 License，或者文件夹里的 `LICENSE` | 没有许可证（不能随便复制、分享） |
| 2 | **作者和更新时间** | 仓库首页的提交记录 | 刚建几天就几千星；很久没人维护 |
| 3 | **说明书写了什么** | 打开 `SKILL.md` 读一遍，看不懂英文就让 AI 翻译 | 要求 AI “不要告诉用户”“跳过确认”“忽略之前的规则” |
| 4 | **有没有脚本** | 文件夹里有没有 `.py`、`.js`、`.sh` 文件 | 脚本会删文件、改系统设置、往陌生网址发数据 |
| 5 | **要不要钥匙、密码** | 说明书里有没有 `API_KEY`、`token`、“登录”、“密码” | 让你把密码、银行卡、身份证发给 AI |
| 6 | **用途正不正当** | 看它宣传自己能做什么 | “降 AIGC 率”“过查重”“批量刷号”“绕过检测” |

**星数不能全信。** 星可以刷。一个 skill 星多，不代表它安全，也不代表它适合你。

## 2. 让 DSH 帮你看（只能参考）

在 DSH 里新建会话，权限选「**仅可查看**」，把 skill 文件夹下载到练习文件夹后发：

```text
请检查「某某skill」文件夹里的所有文件（包括脚本），不要运行任何东西，只告诉我：
1. 这个 skill 是做什么的，什么时候会被用上
2. 有没有脚本？每个脚本做什么？
3. 会不会联网？会访问哪些网址？
4. 需不需要 API 钥匙、账号或密码？
5. 会不会读写工作区以外的文件，或者删除文件？
6. 有没有让你“跳过确认”“不告诉用户”之类的话？
```

> [!WARNING]
> AI 的检查**只能参考**。写坏 skill 的人可能在文件里藏“骗 AI”的话（教程第 25 章讲的“提示词注入”）。**来源不明、又带脚本的 skill，最好别装。**

## 3. 第一次用：在练习文件夹里试

1. 建一个空的练习文件夹，比如 `ai-练习/skill-试用`
2. 选它当工作区，权限选「**工作区内修改**」
3. 放几份**假数据**进去试，不要一上来就用真实文件
4. 看 AI 每次请求权限时要做什么，觉得不对就点「拒绝」

用顺手了，再拿到真正的工作里。

## 4. 哪些身份要格外小心

| 身份 | 特别注意 |
|---|---|
| 🎓 学生 | 用途要符合学校规定，代写论文、降查重的 skill 不要碰 |
| 👩‍🏫 老师 | 会保存学生档案的 skill：确认数据存在哪里、谁能看到 |
| 🧾 会计 | 会读邮箱、读银行流水的 skill：确认数据**不会被发到模型以外的地方** |
| 🛒 电商 | 会登录店铺后台、自动发布的 skill：先确认不违反平台规则 |
| 🎬 自媒体 | 会自动上传、发布的 skill：确认它不会替你乱发 |
