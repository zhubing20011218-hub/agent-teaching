# 按身份找 Skill

> 每个身份挑了几个 GitHub 上公开、许可证允许、我们看过内容的 skill。
> **先装「[通用 Skill](general)」，再从这里挑一两个。** 每个身份的完整实操流程，在「[按身份学](/roles/)」里。
>
> 标记说明：📄 纯说明 · ⚙️ 带脚本 · 🌐 会联网 · 🇨🇳 中文。下面的 skill 许可证都是 MIT，另有说明的除外。

## 🎓 大学生

| Skill | 能帮你做什么 | 标记 | 链接 |
|---|---|---|---|
| `lecture-notes` | 把课件整理成复习手册：概念讲解、准确定义、每道例题的完整解答（英文说明，可以要求输出中文） | ⚙️ | [打开](https://github.com/SaB11F/lecture-notes-skill/tree/main/skills/lecture-notes) |
| `quiz-generator` | 把题目做成离线自测网页：答题卡、错题本、随机抽题 | ⚙️ 🇨🇳 | [打开](https://github.com/fall-dust/quiz-generator-skill) |
| `sunzi-reading`（孙子读论文） | 用大白话讲论文：想解决什么、怎么做的、发现了什么。适合第一次读某个领域的论文 | 📄 🇨🇳 | [打开](https://github.com/julilaoshi/sunzi-reading/tree/main/skill) |
| `paper-reading` | 精读论文，生成中文阅读笔记：主线、方法、图表、公式 | ⚙️ 🌐 🇨🇳 | [打开](https://github.com/Kingslayer-bot/paper-reading-skill) |
| `literature-review-skills`（6 个） | 写课程论文、开题时用：收窄题目、拆分结构、比较研究方法、梳理矛盾、找研究空白 | ⚙️ 🇨🇳 | [打开](https://github.com/xingtaxueshu/literature-review-skills) |
| `learning-tutor` | 想系统自学一门课：先定计划，再一课一课教，每课布置小任务并批改 | 📄 🇨🇳 | [打开](https://github.com/MyLiya46/learning-tutor/tree/main/skills/learning-tutor) |

**原则：** 用 AI **帮你学懂、帮你找资料**，不让 AI **替你写要交的东西**。先看学校和课程的 AI 使用规定。

→ 实操流程：[按身份学 · 大学生](/roles/student)
