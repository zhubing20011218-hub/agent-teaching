# Skill 库：别人写好的“说明书”，拿来就用

> **这一页告诉你：**
> - 这个 Skill 库收了哪些 skill，按什么挑的
> - 从 GitHub 上把一个 skill 装进 DSH 的完整步骤
>
> **前置：** 教程第 14、15 章（知道 skill 是什么，会装 skill）

## 1. 先认识 AI，再用 AI 干活

教程的前半部分，是带你**认识 AI**：API、钥匙、DSH 都是什么。

真正帮到你的，是**用 AI 把手上的事做完**。skill 就是最快的那条路：别人已经把“怎么做好一件事”写成了说明书，你装上就能用。

这个 Skill 库分三部分：

| 页面 | 里面有什么 | 适合谁 |
|---|---|---|
| [通用 Skill](general) | Word、Excel、PPT、PDF、查证资料……人人用得上 | 所有人，**先从这里开始** |
| [按身份找 Skill](by-role) | 学生、老师、会计、电商、自媒体、宠物主人、旅行爱好者，各自的专属 skill | 找和你工作对口的 |
| [不推荐的 Skill](avoid) | 看起来很火，但有问题的 skill，以及为什么 | 所有人，装之前看一眼 |

每个身份的**完整实操流程**，在顶部导航的「[按身份学](/roles/)」里。

## 2. 我们怎么挑 skill

每个 skill 收进来之前，都按下面 5 条检查过（核对日期见每页开头）：

1. **公开，并且许可证允许使用**：MIT、Apache 2.0 这类。没有许可证的只放链接，不复制内容
2. **用途正当**：帮人代写论文、刷检测、违反平台规则的，一律不收（见「[不推荐的 Skill](avoid)」）
3. **看过它的说明和脚本**：标出它会不会**联网**、要不要**钥匙**、会不会**运行脚本**
4. **对新手友好**：能用 DSH 跑起来，不需要先搭服务器
5. **还在维护**：最近一年有更新

> [!WARNING]
> **我们检查过，不等于绝对安全。** 作者随时可能更新内容。装之前，按「[安装前的安全检查](safety-check)」自己再看一遍，尤其是带脚本的 skill。

## 3. 表格里的标记是什么意思

| 标记 | 意思 |
|---|---|
| 📄 纯说明 | 只有文字说明书，没有脚本。最安全 |
| ⚙️ 带脚本 | 里面有程序，AI 会运行它。装之前要看一眼 |
| 🌐 会联网 | 会访问网络，比如搜索、下载 |
| 🔑 要钥匙 | 需要另外申请某个服务的 API 钥匙，可能要花钱 |
| 🇨🇳 中文 | 说明书是中文写的 |

## 4. 从 GitHub 装一个 skill：完整步骤

以通用 Skill 里的 `xlsx`（处理 Excel）为例。

### 第一步：找到 skill 文件夹

1. 打开表格里的链接，比如 https://github.com/anthropics/skills/tree/main/skills/xlsx
2. 确认这个文件夹里**直接**有一个 `SKILL.md` 文件

> [!TIP]
> GitHub 上很多仓库是“skill 合集”，一个仓库里有好几个 skill。**你要的是里面某一个 skill 的文件夹**，不是整个仓库。

### 第二步：让 DSH 帮你装（推荐）

1. 在 DSH 里新建一个会话，权限选「**工作区内修改**」
2. 发这段话（把网址换成你要装的那个）：

```text
请帮我安装这个 skill:
https://github.com/anthropics/skills/tree/main/skills/xlsx

要求：
1. 只下载 xlsx 这一个文件夹，放到 ~/.dsh/skills/xlsx/
2. 确认 ~/.dsh/skills/xlsx/SKILL.md 存在，不要多套一层文件夹
3. 安装前先告诉我：这个 skill 里有没有脚本、会不会联网、需不需要钥匙
4. 等我确认后再安装
```

3. 读 AI 的回答。没问题就回复“可以，安装吧”
4. DSH 请求权限时，看清楚它要做什么，再点「允许一次」

**应该看到：** 装好后，在输入框里打 `/`，能找到 `xlsx`。

### 第三步：测试它真的会用

按教程第 15 章第 6 节的三个测试做一遍：让 AI 自己判断、手动指定、不该用的时候不用。

> [!TIP]
> 带脚本的 skill 第一次用时，AI 可能要先安装一些工具（比如 Python 的库）。它请求运行命令时，看清楚命令再允许。不确定就问它：“这条命令是做什么的？”

## 5. 用完之后

- 好用的 skill，可以按教程第 19 章改成**你自己的版本**，比如加上你学校、公司的格式要求
- 不用的 skill 就卸载（第 15 章第 8 节）。装太多，AI 反而容易挑错
- 发现某个 skill 有问题，或者想推荐好用的，欢迎到 GitHub 反馈
