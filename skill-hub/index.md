# Skill 库

> 300 多个 skill，按领域整理。每一个都下载源码检查过：说明书和脚本都读过，格式按 DSH 的规则验证过（没有逐个实际运行）。左边选领域，或者直接搜索。
>
> **装法只有两步：** 点「**复制安装指令**」→ 粘贴到 DSH 发送。DSH 会先告诉你这个 skill 有没有脚本、会不会联网，你确认后它再安装。

## 安装前，花三分钟看一眼 {#safety}

skill 是写给 AI 的说明书，装上后 AI 会照着做，包括运行里面的脚本。

| 看什么 | 🚩 遇到这些就别装 |
|---|---|
| 说明书里写了什么 | 要 AI “不要告诉用户”“跳过确认”“忽略之前的规则” |
| 有没有脚本（⚙️） | 脚本会删文件、改系统设置、往陌生网址发数据 |
| 要不要钥匙、密码 | 要你把密码、银行卡、身份证发给 AI |
| 用途正不正当 | “降 AIGC 率”“过查重”“批量刷号”“绕过检测” |

**第一次用：** 建一个空的练习文件夹，放几份假数据试，用顺手了再拿到真实工作里。详细方法见[第 12 章](/chapters/12-install-skill)。

> [!TIP]
> GitHub 打不开的话，DSH 一般也下载不了，因为它和你的浏览器走的是同一个网络。标着「本站下载」的 skill 不受影响。

## 这几类 skill 我们不收录 {#avoid}

| 类型 | 原因 |
|---|---|
| 代写论文、降 AIGC 率、过查重、自动生成实验报告、针对 AI 评分系统刷分 | 学术不端，被查出来轻则重写，重则取消学位 |
| 自动炒股、自动交易、预测涨跌 | AI 会编数据，自动下单出错就是真金白银 |
| 批量注册、自动海投简历、自动发布和评论、刷数据 | 违反平台规则，容易被封号 |
| 要你把账号密码写进配置文件的 | 密码可能被同步、上传、泄露 |
| 一个仓库里塞一百多个 skill 的 | AI 容易挑错，质量和许可证参差不齐 |
