# 补截图说明

需要截图的位置,都在章节源文件里用**注释**标出来了,网页上不会显示。格式是:

```markdown
<!-- 截图待补:设置 → 模型 页面。补图方法见 docs/screenshots.md -->
```

## 怎么补一张图

1. **截图并打码**:钥匙、邮箱、手机号、账号名、真实文件路径里的用户名,全部打码
2. **压缩**:尽量用 `.png` 或 `.webp`,单张不超过 300KB(服务器上传慢,图片越小越好)
3. **起名**:用英文小写和短横线,前面加章节号,例如 `09-settings-models.png`
4. **放进** `chapters/images/` 文件夹
5. **把那行注释换成图片**:

```markdown
![设置 → 模型 页面](./images/09-settings-models.png)
```

`![ ]` 方括号里写一句话说明这张图是什么(看不到图的人也能明白)。

## 查还有哪些没补

在项目文件夹里运行:

```bash
grep -rn "截图待补" chapters
```
