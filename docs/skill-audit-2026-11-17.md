# Skill 库审查记录（2026-11-17，第二轮）

calmness 反馈：低星、难用的不要；通用的要多；每个都要看源码确认真的有用。第二轮按“质量和通用性优先”重新筛选。

## 结果

- 下载 56 个公开仓库的源码，共 **2,289 个 skill**；按 DSH 规则格式合格 **2,257 个**
- 收录 **249 个**（其中 8 个由本教程编写），分 20 个领域；新手推荐 25 个

## 筛选规则

1. **仓库 ≥300 星，近半年有更新**（本教程自带的除外）
2. **说明书质量分 ≥5（满分 7）**：长度合适（800–40,000 字符）、有分步流程、有输出模板、有示例、写明什么时候用；依赖的外部服务（CRM、Slack 等）超过 2 个扣分
3. **通用、好上手**：太专业（生物信息、量子计算等）、要付费钥匙、只适用于某一家公司或某一个国家细分法规的不收
4. 分数在 5 分以下、但人工看过确实扎实的（主要是 Anthropic 官方的 Word、Excel、PPT、PDF 等），人工放行，名单写在 `select2.py` 的 `KEEP_LOW`

## 这一轮发现并排除的

| 问题 | 例子 |
|---|---|
| **说明书几乎是空的**（真正内容在仓库别处，单独装没用） | 某合集里的深度工作、每周复盘、反思、想法整理、领英、法务顾问等十几个 |
| 低星、维护少 | 星数个位数到两百多的十几个（包括第一轮收的部分中文 skill） |
| 太专业、难上手 | 生物信息、化学、天文、量子计算、贝叶斯统计等 |
| 要付费服务或钥匙 | AI 画科研示意图、Zotero、OpenRouter 出图等 |
| 自动发布、读取聊天记录或浏览器登录信息 | 自动发公众号 / 微博 / X、读取本地微信聊天记录、读取浏览器 Cookie |
| 面向高管的顾问类 | CEO / COO / CFO / CISO 顾问等，太窄 |
| 重名 | 同名的保留更好的版本（多为 Anthropic 官方） |

第一轮发现的两个真问题（要求 AI“不要告诉用户”“不问用户确认”的法律 skill）继续排除。
