# Skill 库审查记录（2026-11-17）

## 范围

- 下载 39 个公开仓库的源码，共 **1,468 个 skill**
- 按 DSH 0.2.2-rc.3 的规则检查格式：**1,448 个通过**；20 个不通过（名字格式不对 14、头部信息写错 4、缺头部信息 1、缺 name/description 1），DSH 无法识别，全部排除
- 按领域挑选后收录 **309 个**

## 检查了什么

1. **格式**：头部信息以 `---` 开始和结束、能被 YAML 解析；有 `name` 和 `description`；`name` 只用小写字母、数字、短横线；没有 DSH 不支持的旧字段
2. **说明书和全部脚本**：联网调用、危险命令（`sudo`、`rm -rf ~`、`curl | sh`、改 shell 配置、读 SSH 钥匙或钥匙串、读 DSH 凭据、可疑的外传网址）、需要的钥匙、“不要告诉用户 / 忽略之前的规则”这类话
3. **对外引用**：说明书里 `../` 开头、指向文件夹外面的引用（单独安装会缺文件的，要么在安装指令里补上，要么排除）

**没有做的：** 没有逐个实际运行（不真实调用 API；很多 skill 需要特定文件或账号）。

## 人工复核结果

扫描标记了 67 个，逐行看过：

- **误报**：变量名叫 `profile`、安全扫描类 skill 里列出的“危险命令清单”、安装说明里的 `sudo apt install`、本机进程通信用的 `AF_UNIX` 套接字等
- **真问题，已排除**：
  - 一个法律 skill 要求 AI“在后台悄悄做，**不要告诉用户**”
  - 一个法律 skill 要求 AI“自己下结论，**不要问用户确认**”

## 其他排除

| 排除 | 原因 |
|---|---|
| 和已收录 skill 重名的两个（另一个 `fact-check`、另一个 `contract-review`） | 同名会互相覆盖 |
| 两个合规审计 skill | 会运行仓库里其他文件夹的脚本，单独安装会坏 |
| 只适用于某一家公司风格的三个（某公司博客规范、品牌配色、品牌幻灯片） | 对读者没用 |
| 股票分析、自动交易类 | 不提供投资建议 |
| 外链建设、批量提交目录、自动发帖评论类 | 容易违反平台规则 |
| 代写论文、降 AIGC、自动生成实验报告类 | 学术不端 |

## 需要读者注意的

- 电商合集里有 10 个 skill 要用到仓库根目录的 `references`、`scripts` 文件夹，安装指令里已写明
- 法律类多针对美国、欧盟法律；许可证为 CC BY-NC-ND 4.0（个人使用可以，不能改编后再分发）
- 产品管理类许可证为 CC BY-NC-SA 4.0（非商业使用）
- 标了 🔑 的要另外申请账号或钥匙；标了 🧰 的要先装软件
